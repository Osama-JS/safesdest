هندسة النظام
وتصميم التكامل

كيف يتكامل نظام الشركات مع نظام المهام الحالي، محرك التسعير، وإدارة نقاط المهمة — مع الحفاظ على عزل تام عن سير العمل الاعتيادي.

القسم 3.1 — مبدأ العزل

تكامل دون أي تأثير على النظام الحالي

القاعدة الذهبية لهذا التنفيذ: إنشاء المهام للعملاء العاديين يجب أن يظل دون أي تأثير مطلقاً. نقطة التفرع واضحة وشرطية.

✅

نقطة كشف الشركة

نقطة التفرع الوحيدة هي عند اختيار العميل في نموذج المهمة. إذا كان customer.is_company === true، يُفعَّل نظام الشركات في الواجهة والتسعير. وإلا يسير النظام الحالي بالكامل كما هو اليوم دون أي تغيير.

⚠️

لا يوجد اشتراك في جداول التسعير

تسعير الشركات لا يستخدم جداول pricing_templates أو pricing أو pricing_methods. يستخدم جداوله المعزولة الخاصة. هذا يمنع أي تلوث غير مقصود لمنطق التسعير.

// الخطوة 1: محاولة سعر التجاوز الخاص بالعميل (الأعلى أولوية) $clientPrice = Company_Client_Pricing:: where('warehouse_id', $warehouseId) ->where('end_client_id', $client->id) ->first(); if ($clientPrice) { return $clientPrice->price; // ← استخدام هذا السعر } // الخطوة 2: محاولة سعر المسار (مخزن + محافظة) $routePrice = Company_Route_Pricing:: where('warehouse_id', $warehouseId) ->where('destination_province', $client->province) ->first(); if ($routePrice) { return $routePrice->price; // ← استخدام هذا السعر } // الخطوة 3: لا يوجد سعر → استثناء خطأ throw new PricingNotFoundException('No route pricing for this combination');
القسم 3.4 — التعبئة التلقائية للنقاط

كيف تُنشأ نقاط المهمة تلقائياً

عند حفظ مهمة شركة، يعترض TasksController الحفظ ويبني سجلات tasks_points من بيانات المخزن والعميل تلقائياً — دون أي إدخال يدوي للعنوان.

// TasksController — داخل store() للمهام التابعة لشركة $warehouse = Company_Warehouse::findOrFail($req->company_warehouse_id); $client = Company_End_Client::findOrFail($req->company_end_client_id); // إنشاء نقطة الاستلام من المخزن Task_Points::create([ 'task_id' => $task->id, 'type' => 'pickup', 'contact_name' => $warehouse->contact_name, 'contact_phone'=> $warehouse->contact_phone, 'address' => $warehouse->address, 'latitude' => $warehouse->latitude, 'longitude' => $warehouse->longitude, ]); // إنشاء نقطة التسليم من العميل النهائي Task_Points::create([ 'task_id' => $task->id, 'type' => 'delivery', 'contact_name' => $client->name, 'contact_phone'=> $client->phone, 'address' => $client->address ?? $client->province, ]);
