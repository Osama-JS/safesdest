HyperSplits 2.0 API Documentation
1. Environment
The HyperSplits 2.0 API is currently available in the following environment:
Sandbox Environment
Base URL: https://gateway.sandbox.hyperpay.com
All API endpoints documented in this guide use relative paths and must be
appended to the base URL.
Example:
POST {Base URL}/payouts

2. Authentication
Authentication Method
All HyperSplits API requests use Basic Authentication.
To access the API, you will use three authentication elements:
• Username
• Password
• Merchant Identifier
To authenticate a request:
1. Combine the username and password as username:password.
2. Encode this value in Base64.
3. Add the encoded value in the Authorization header using the format:
Authorization: Basic <Base64(username:password)>
4. Add your assigned partner identifier in the X-Merchant-Id header.
5. Set Content-Type to application/json.
Every API request must include these authentication elements to be accepted.

3. Create Payout
Endpoint:
POST /payouts
Create Payout enables you to pay out funds to beneficiary bank accounts. This
API supports bulk payouts, allowing multiple transfers within a single request.
Required Headers
Name            Type            Required            Description
Content-Type    string            Yes               Must be application/json
Authorization   string            Yes               Basic Base64<username:password>
X-Merchant-Id   Alphanumeric      Yes               Add your assigned partner identifier

Request Body
Field                     Type            Required          Description
merchantReference         Alphanumeric    Yes               Identifier for the bulk payout request
sourceId                  Alphanumeric    Yes               Unique identifier for the source account at HyperPay
payouts                   Array           Yes               Array of payout objects.
payouts.transferMode      Alpha           Yes               Accepted values: INSTANT,DATE
payouts.amount            decimal         Yes               Payout amount formatted according to currency rules
payouts.currency          Alpha           Yes               ISO 4217 three-letter currency code, for example SAR
payouts.transferDate      Date            Conditional       Required if transferMode = DATE. value = "YYYY-MM-DD"
payouts.description       Alphanumeric    No                Payout description
payouts.payoutReference   Alphanumeric    Yes               Merchant unique reference for each payout
payouts.purpose           Alphanumeric    Yes               Purpose of the transfer as per of bank transfer codes
payouts.channel           Alpha           No                Routes the payout to a specific payment channel, overriding the default channel selection logic. When omitted, the channel is determined automatically based on the payout amount — IPS for amounts below 20,000 SAR, and SARIE for amounts of 20,000 SAR or above. Accepted values: IPS, SARIE, INTRA_BANK
payouts.beneficiary       Object          Yes               Beneficiary details
beneficiary.id            Alphanumeric    No                Id of an existing beneficiary
beneficiary.name           Alphanumeric    Yes               Name of the beneficiary as per bank account details
beneficiary.address1      Alphanumeric    Yes               Address line 1 of the beneficiary as per bank account details
beneficiary.address2      Alphanumeric    Yes               Address line 2 of the beneficiary as per bank account details
beneficiary.accountNumber Numeric         No                Internal bank account number. This parameter should be used when the channel is INTRA_BANK
beneficiary.iban          Alphanumeric    No                Destination IBAN. This parameter should be used when the destination bank account is different from the source bank account beneficiary.bicCode Alpha No Destination bank BIC code. This parameter is mandatory if IBAN is provided
beneficiary.country       Alpha           No                Country of the beneficiary. ISO 3166-1 alpha-2
beneficiary.city          Alpha           No                City of the beneficiary



Response Structure
Field                           Description
merchantReference               Identifier for the bulk payout request
responseCode                    5-digits response code
responseMessage                 message describing the response code
payouts.payoutId                HyperPay unique payout ID
payouts.bulkId                  HyperPay unique bulk ID
payouts.payoutReference         Merchant unique reference for each payout
payouts.purpose                 Purpose of the transfer as per bank transfer codes
payouts.amount                  Payment amount formatted according to currency rules
payouts.currency                ISO 4217 three-letter currency code, for example SAR
payouts.transferDate            Date of the scheduled transfer as received in the request
payouts.description             Payout description
payouts.responseCode            5-digit response code indicating the status of each payout object
payouts.responseMessage         message describing the response code

4. Get Payout Status
Endpoint:
GET /payout
Get Payout Status enables you to retrieve the current status of a payout using the
payoutReference or payoutId. This API supports inquiry for a single payout per
request.

Required Headers
Name              Type          Required      Description
Authorization     string        Yes           Basic Base64<username:password>
X-Merchant-Id     Alphanumeric  Yes           Add your assigned partner identifier

Request Query Parameters
Field              Type           Required      Description
payout-reference   Alphanumeric   No            Merchant unique Identifier for the payout
payout-id          Alphanumeric   No            HyperPay unique identifier assigned to the payout.

Response Structure
Field                       Description
merchantReference           Identifier for the bulk payout request
responseCode                5-digit response code
responseMessage             message describing the response code
payouts.payoutId            HyperPay unique payout ID
payouts.bulkId              HyperPay unique bulk ID
payouts.payoutReference     Merchant unique reference for each payout
payouts.purpose             Purpose of the transfer as per bank transfer codes.
payouts.amount              Payment amount formatted according to currency rules
payouts.currency            ISO 4217 three-letter currency code, for example SAR
payouts.transferDate        Date of the scheduled transfer as received in the request
payouts.description         Payout description


Example Request (cURL)
curl --location 'https://gateway.sandbox.hyperpay.com/payout?payoutreference=PAYOUT-20260222-0001' \
--header 'X-Merchant-Id: XXX' \

5. Cancel Payout
Endpoint:
PUT /payouts/cancel
Cancel Payout enables you to cancel a created payout that has not yet been
processed using the payout-reference or payoutId.
Required Headers
Name                Type          Required    Description
Content-Type        string        Yes         Must be application/json
Authorization       string        Yes         Basic Base64<username:password>
X-Merchant-Id       Alphanumeric  Yes         Add your assigned partner identifier

Request Body
Field               Type          Required    Description
payoutId            Alphanumeric  No          Payout unique identifier assigned by HyperPay for the payout
payoutReference     Alphanumeric  No          Merchant unique Identifier for the
payout
Response Structure
Field              Description
responseCode       5-digits response code
responseMessage    message describing the response

Sample Request (cURL)
curl --location --request PUT
'https://gateway.sandbox.hyperpay.com/payouts/cancel' \
--header 'X-Merchant-Id: XXX' \
--header 'Content-Type: application/json' \
--header 'Authorization: Basic XXX' \
--data '{
 "payoutId": "07444621-c232-44d6-8cb0-5e525a7dbde6"
}'
Sample Response
{
 "responseCode": "77000",
 "responseMessage": "Transaction cancelled"
}

notification to the merchant’s configured webhook URL containing the final
payout status.
