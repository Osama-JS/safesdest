  • جميع النسخ عالقة في حالة "processing"

  • كلمات مرور ضعيفة وقابلة للتنبؤ
  • تشفير جزئي فقط
  • عدم دعم PostgreSQL بشكل صحيح

  • عدم وجود تسجيل مفصل

  • نظام إنشاء نسخ موثوق 100%

  • تشفير AES-256 للأرشيف كاملاً

  • معالجة أخطاء شاملة ومتقدمة

الميزات الأمنية المحسنة

كلمات مرور عشوائية آمنة:

استخدام random_bytes(32) لتوليد كلمات مرور 64 حرف عشوائية تماماً

return bin2hex(random_bytes(32)); // 64-character secure password
تشفير AES-256 شامل:

تشفير جميع ملفات الأرشيف بدلاً من ملف واحد فقط

foreach ($files as $file) { $zip->addFile($file->getPathname(), $relativePath); $zip->setEncryptionName($relativePath, ZipArchive::EM_AES_256); }
دعم PostgreSQL محسن:

أوامر pg_dump و psql محسنة مع معالجة آمنة لكلمات المرور

// Secure PGPASSWORD handling $originalPgPassword = getenv('PGPASSWORD'); putenv('PGPASSWORD=' . $dbConfig['password']); // ... execute command ... // Restore original environment
تشفير كلمات المرور:

حفظ كلمات مرور النسخ مشفرة باستخدام Laravel Crypt

$passwords[$backupName] = Crypt::encrypt($password);
التحقق من سلامة النسخ:

فحص تلقائي لصحة النسخ بعد الإنشاء

if (!File::exists($zipPath) || File::size($zipPath) === 0) { throw new Exception('Backup archive was not created or is empty'); }

الدوال والميزات الجديدة

دوال جديدة مضافة
دوال الأمان:
  • generateSecurePassword() - توليد كلمات مرور آمنة
  • storeBackupPassword() - حفظ كلمات المرور مشفرة
  • getBackupPassword() - استرجاع كلمات المرور
  • removeBackupPassword() - حذف كلمات المرور
دوال النسخ والاستعادة:
  • createPostgreSQLBackup() - نسخ PostgreSQL محسن
  • extractBackup() - استخراج النسخ الآمن
  • restoreDatabase() - استعادة قاعدة البيانات
  • restoreFiles() - استعادة الملفات

اختبار النظام

جاهز للاختبار

النظام جاهز للاختبار بمجرد تثبيت أدوات PostgreSQL على الخادم.

خطوات الاختبار المطلوبة
  1. تثبيت أدوات PostgreSQL:
    # على Ubuntu/Debian sudo apt-get install postgresql-client # على CentOS/RHEL sudo yum install postgresql # على Windows # تحميل وتثبيت PostgreSQL من الموقع الرسمي
  2. التحقق من التثبيت:
    pg_dump --version psql --version
  3. اختبار إنشاء نسخة احتياطية:
    • الدخول إلى لوحة الإدارة
    • الانتقال إلى الإعدادات → النسخ الاحتياطي
    • إنشاء نسخة احتياطية جديدة
    • التحقق من حالة النسخة (يجب أن تكون "completed")
  4. اختبار استعادة النسخة:
    • اختيار نسخة احتياطية مكتملة
    • تشغيل عملية الاستعادة
    • التحقق من استعادة البيانات بنجاح

تنظيف النسخ العالقة

دالة تنظيف تلقائية للنسخ العالقة:

public function cleanupStuckBackups() { $backups = $this->getBackupsList(); $cleaned = 0; foreach ($backups as $backup) { if ($backup['status'] === 'processing') { $createdAt = Carbon::parse($backup['created_at']); if ($createdAt->diffInHours(Carbon::now()) > 1) { $this->updateBackupInfo($backup['name'], [ 'status' => 'failed', 'error' => 'Backup timed out' ]); $cleaned++; } } } return response()->json([ 'status' => 1, 'message' => "Cleaned up {$cleaned} stuck backups" ]); }
