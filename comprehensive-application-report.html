🔌 3. واجهات البرمجة الخلفية (Backend APIs)

🔐 نظام المصادقة (Authentication APIs)

POST /api/driver/login

الوصف: تسجيل دخول السائق وإنشاء Sanctum token

المعاملات:

{ "email": "driver@example.com", "password": "password123", "device_name": "iPhone 12", "device_id": "unique_device_id", "fcm_token": "firebase_token", "app_version": "1.0.0" }

الاستجابة:

{ "success": true, "message": "Login successful", "data": { "driver": { /* بيانات السائق */ }, "token": "sanctum_token_here", "abilities": ["driver:read", "tasks:manage", ...] } }

الاستخدام: تطبيق Flutter للسائقين

POST /api/driver/logout

الوصف: تسجيل خروج السائق وإلغاء الـ token

المصادقة: Bearer Token مطلوب

الاستخدام: عند خروج السائق من التطبيق

POST /api/driver/refresh-token

الوصف: تجديد الـ token وتحديث بيانات الجهاز

الاستخدام: تجديد دوري للمصادقة

📋 إدارة المهام (Task Management APIs)

GET /api/driver/tasks

الوصف: جلب قائمة المهام المتاحة للسائق

المعاملات الاختيارية:

?status=pending&page=1&per_page=10

الاستجابة:

{ "success": true, "data": [ { "id": 1, "status": "pending", "total_price": 150.00, "pickup": { "address": "الرياض، حي النخيل", "latitude": 24.7136, "longitude": 46.6753 }, "delivery": { "address": "جدة، حي الروضة", "latitude": 21.3891, "longitude": 39.8579 }, "customer": { "name": "أحمد محمد", "phone": "+966501234567" } } ], "pagination": { /* معلومات التصفح */ } }

الاستخدام: شاشة المهام في تطبيق السائق

POST /api/driver/tasks/{id}/accept

الوصف: قبول مهمة معينة

العملية:

  1. التحقق من توفر السائق (free = true, online = true)
  2. تحديث حالة المهمة إلى "accepted"
  3. ربط المهمة بالسائق (driver_id)
  4. تحديث حالة السائق إلى مشغول (free = false)
  5. إرسال إشعار للعميل

الاستخدام: عند الضغط على "قبول المهمة"

PUT /api/driver/tasks/{id}/status

الوصف: تحديث حالة المهمة أثناء التنفيذ

الحالات المتاحة:

  • picked_up: تم استلام البضاعة
  • in_transit: في الطريق للتسليم
  • delivered: تم التسليم

المعاملات:

{ "status": "picked_up", "notes": "تم استلام البضاعة بحالة جيدة", "location": { "latitude": 24.7136, "longitude": 46.6753 } }

الاستخدام: تتبع مراحل تنفيذ المهمة

📍 إدارة المواقع (Location Management APIs)

POST /api/driver/location

الوصف: تحديث موقع السائق الحالي

المعاملات:

{ "latitude": 24.7136, "longitude": 46.6753, "accuracy": 5.0, "timestamp": "2024-08-19T10:30:00Z" }

العملية:

  • تحديث إحداثيات السائق في قاعدة البيانات
  • تسجيل وقت آخر نشاط (last_activity_at)
  • تحديث حالة الاتصال (last_seen_at)

الاستخدام: تتبع موقع السائق في الوقت الفعلي

POST /api/driver/status

الوصف: تحديث حالة السائق (متصل/غير متصل، متاح/مشغول)

المعاملات:

{ "online": true, "free": true }

الاستخدام: تبديل حالة السائق من التطبيق

POST /api/driver/fcm-token

الوصف: تحديث رمز Firebase للإشعارات الفورية

الاستخدام: عند تحديث التطبيق أو تغيير الجهاز

🔐 نظام المصادقة في Flutter

🔑 AuthService

الملف: lib/services/auth_service.dart

الوظائف الرئيسية:

  • login(): تسجيل الدخول وحفظ الـ token
  • logout(): تسجيل الخروج ومسح البيانات
  • refreshToken(): تجديد الـ token
  • isAuthenticated(): التحقق من حالة المصادقة
  • getStoredToken(): جلب الـ token المحفوظ

🔄 آلية عمل المصادقة

  1. تسجيل الدخول: إرسال بيانات الاعتماد إلى /api/driver/login
  2. حفظ البيانات: تخزين الـ token في Flutter Secure Storage
  3. إضافة Headers: إرفاق Bearer token مع كل طلب API
  4. التحقق التلقائي: فحص صلاحية الـ token عند بدء التطبيق
  5. التجديد: تجديد الـ token عند انتهاء الصلاحية

  1. عرض المهام: جلب قائمة المهام المتاحة

⚙️ 6. العمليات والوظائف التفصيلية

🔄 عملية إنشاء مهمة جديدة (من البداية للنهاية)

🎯 العملية الأكثر تعقيداً في النظام: تتضمن التسعير التلقائي، توزيع المهام، والتتبع المباشر.

📋 المراحل التفصيلية:

  1. إدخال البيانات:
    • العميل يدخل نقطة الاستلام والتسليم
    • اختيار نوع المركبة المطلوبة
    • إدخال تفاصيل البضاعة والملاحظات
    • تحديد الأولوية والوقت المطلوب
  2. حساب التسعير التلقائي:
    • استخدام Mapbox API لحساب المسافة والوقت
    • تطبيق قواعد التسعير حسب المنطقة الجغرافية
    • إضافة رسوم إضافية (حجم البضاعة، الأولوية)
    • حساب العمولة للسائق والمنصة
  3. التحقق من الصحة:
    • التأكد من صحة العناوين والإحداثيات
    • فحص رصيد العميل
    • التحقق من توفر السائقين في المنطقة
    • فحص القيود الجغرافية والزمنية
  4. إنشاء المهمة:
    • حفظ بيانات المهمة في قاعدة البيانات
    • إنشاء نقاط الاستلام والتسليم
    • تسجيل تفاصيل التسعير
    • إنشاء سجل تاريخ المهمة
  5. توزيع المهمة:
    • البحث عن السائقين المتاحين في المنطقة
    • ترتيب السائقين حسب المسافة والتقييم
    • إرسال إشعارات للسائقين المؤهلين
    • بدء عداد انتظار الاستجابة
  6. قبول المهمة:
    • السائق يقبل المهمة من التطبيق
    • تحديث حالة المهمة إلى "accepted"
    • ربط المهمة بالسائق
    • إرسال إشعار للعميل
    • بدء تتبع الموقع المباشر
  7. تنفيذ المهمة:
    • السائق ينتقل لنقطة الاستلام
    • تأكيد الاستلام مع الصور
    • الانتقال لنقطة التسليم
    • تأكيد التسليم والحصول على التوقيع
  8. إنهاء المهمة:
    • تحديث حالة المهمة إلى "completed"
    • حساب الأرباح وتوزيعها
    • إرسال الفاتورة للعميل
    • طلب تقييم الخدمة
    • تحديث إحصائيات السائق
