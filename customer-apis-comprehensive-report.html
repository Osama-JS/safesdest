📋4. إدارة المهام (Tasks Management)

🚚 المهام الأساسية

API Endpoint Method الوصف الأولوية
/api/customer/tasks GET قائمة مهام العميل مع الفلترة والبحث عالية
/api/customer/tasks POST إنشاء مهمة جديدة عالية
/api/customer/tasks/{id} GET تفاصيل مهمة محددة عالية
/api/customer/tasks/{id} PUT تحديث بيانات المهمة متوسطة
/api/customer/tasks/{id}/cancel POST إلغاء المهمة متوسطة
/api/customer/tasks/{id}/track GET تتبع المهمة في الوقت الفعلي عالية
/api/customer/tasks/{id}/history GET تاريخ المهمة والتحديثات متوسطة
/api/customer/tasks/{id}/rate POST تقييم السائق والخدمة متوسطة

📝 أنواع المهام المدعومة:

  • مهمة داخلية (normal) - باستخدام task_template
  • مهمة من الميناء (task_from) - باستخدام task_from_port_template
  • مهمة إلى الميناء (task_to) - باستخدام task_to_port_template
  • مهام مباشرة (تعيين سائق مباشر)
  • مهام معلنة (advertised) - للمزايدة

📊 حالات المهام الفعلية:

  • in_progress - قيد التنفيذ
  • advertised - معلن للمزايدة
  • assign - مُعين لسائق
  • started - بدأت
  • in pickup point - في نقطة الاستلام
  • loading - جاري التحميل
  • in the way - في الطريق
  • in delivery point - في نقطة التسليم
  • unloading - جاري التفريغ
  • completed - مكتملة
  • canceled - ملغية
  • refund - مرتجع
  • invoiced - مفوتر

🔧 آلية إنشاء المهام:

  • اختيار نوع المهمة (normal/task_from/task_to)
  • تحديد نموذج التسعير (Pricing_Template)
  • تحديد حجم المركبة (Vehicle_Size)
  • ملء الحقول الديناميكية من Form_Template
  • تحديد نقاط الاستلام والتسليم
  • اختيار طريقة التعيين (مباشر أو إعلان)
  • حفظ البيانات في additional_data كـ JSON

💰5. إدارة المحفظة (Wallet Management)

API Endpoint Method الوصف الأولوية
/api/customer/wallet GET بيانات المحفظة والرصيد عالية
/api/customer/wallet/transactions GET قائمة المعاملات المالية عالية
/api/customer/wallet/deposit POST إيداع أموال في المحفظة عالية
/api/customer/wallet/withdraw POST سحب أموال من المحفظة متوسطة
/api/customer/wallet/transfer POST تحويل أموال لعميل آخر منخفضة
/api/customer/wallet/statements GET كشف حساب مفصل متوسطة

💳 أنواع المعاملات المالية الفعلية:

  • credit - إيداع في المحفظة (رصيد موجب)
  • debit - خصم من المحفظة (رصيد سالب)

📝 بيانات المعاملة:

  • amount - المبلغ
  • transaction_type - نوع المعاملة (credit/debit)
  • description - وصف المعاملة (نص حر)
  • image - صورة إيصال (اختياري)
  • maturity_time - تاريخ الاستحقاق
  • task_id - ربط بمهمة (اختياري)
  • clearance_id - ربط بتخليص جمركي (اختياري)
  • sequence - رقم تسلسلي للمعاملة

🏛️6. التخليص الجمركي (Customs Clearance)

API Endpoint Method الوصف الأولوية
/api/customer/customs-clearances GET قائمة طلبات التخليص الجمركي عالية
/api/customer/customs-clearances POST إنشاء طلب تخليص جمركي جديد عالية
/api/customer/customs-clearances/{id} GET تفاصيل طلب التخليص عالية
/api/customer/customs-clearances/{id}/documents POST رفع المستندات المطلوبة عالية
/api/customer/customs-clearances/{id}/status GET حالة التخليص الجمركي متوسطة
/api/customer/customs-clearances/ads GET إعلانات التخليص الجمركي المتاحة متوسطة
/api/customer/customs-clearances/offers POST تقديم عرض للتخليص الجمركي متوسطة

📄 نظام التخليص الجمركي الفعلي:

  • لا يستخدم Form_Template - له نظام منفصل
  • البيانات تُحفظ مباشرة في جدول customs_clearance
  • نظام تاريخ العمليات في customs_clearance_history
  • نظام العروض في customs_clearance_offers
  • رفع الملفات والمستندات حسب الحاجة
  • ربط مع وكلاء التخليص (is_customs_clearance_agent)

🔧 آلية التخليص الجمركي:

  • إنشاء طلب تخليص جمركي
  • تحديد البيانات الأساسية (الوزن، القيمة، النوع)
  • رفع المستندات المطلوبة
  • نشر كإعلان للوكلاء
  • استقبال العروض من الوكلاء
  • قبول عرض وتعيين الوكيل
  • متابعة التنفيذ والدفع

📝10. نظام الحقول الديناميكية (Dynamic Fields System)

API Endpoint Method الوصف الأولوية

🔧 أنواع الحقول الديناميكية المدعومة:

  • number - حقل رقمي
  • string - نص عادي
  • email - بريد إلكتروني
  • select - قائمة اختيار
  • date - تاريخ
  • file - رفع ملف
  • image - رفع صورة
  • file_expiration_date - ملف مع تاريخ انتهاء
  • file_with_text - ملف مع نص

📊 خصائص الحقول:

  • name - اسم الحقل (مفتاح فريد)
  • label - التسمية المعروضة
  • type - نوع الحقل
  • required - إجباري أم لا
  • value - القيمة الافتراضية
  • customer_can - صلاحية العميل (write/read/hidden)
  • driver_can - صلاحية السائق (write/read/hidden)
  • order - ترتيب الحقل
