إصلاح مشكلة tokens() في Customer Model

🚨 وصف المشكلة

الخطأ المكتشف

BadMethodCallException: Call to undefined method App\Models\Customer::tokens() in C:\xampp\htdocs\safedestssss\vendor\laravel\framework\src\Illuminate\Support\Traits\ForwardsCalls.php:67

السبب: نموذج Customer لا يستخدم HasApiTokens trait من Laravel Sanctum، مما يعني أنه لا يمكنه استخدام method الخاص بـ tokens().

الموقع: app/Http/Controllers/Api/CustomerAuthController.php في دالة login

🛠️ الحل المطبق

1إضافة HasApiTokens Import

تم إضافة import للـ HasApiTokens trait في أعلى ملف Customer model:

+ use Laravel\Sanctum\HasApiTokens;

2إضافة HasApiTokens Trait

تم إضافة HasApiTokens trait إلى class Customer:

class Customer extends Authenticatable { use HasRoles; use HasFactory; use SoftDeletes; use HasPushSubscriptions; + use HasApiTokens;

3تنظيف الكود

تم إزالة import غير المستخدم:

- use Illuminate\Database\Eloquent\Model;

🔧 التفاصيل التقنية

ما يوفره HasApiTokens Trait

  • tokens() method: للوصول إلى جميع tokens الخاصة بالمستخدم
  • createToken() method: لإنشاء token جديد
  • currentAccessToken() method: للحصول على token الحالي
  • tokenCan() method: للتحقق من صلاحيات token

الوظائف المتأثرة

  • تسجيل الدخول: إنشاء tokens جديدة للمستخدمين
  • إدارة الجلسات: حذف tokens القديمة
  • تسجيل الخروج: إلغاء tokens النشطة
  • إعادة تعيين كلمة المرور: حذف جميع tokens
