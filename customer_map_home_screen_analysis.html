🗺️ تحليل وتصميم الشاشة الرئيسية بالخريطة

تحليل شامل لمتطلبات تطوير شاشة رئيسية تفاعلية بخريطة MapBox

📋 تحليل المتطلبات

🎯 المتطلبات الأساسية

  • خريطة MapBox: تمتد على كامل الشاشة عدا الشريط السفلي
  • عناصر طافية: اسم المستخدم، أيقونة الإعدادات، أيقونة الإشعارات
  • عرض المهام النشطة: المهام غير المكتملة وغير المفوترة
  • نقاط ذكية: نقاط زرقاء للمهام بدون سائق، أيقونة شاحنة للمهام المعينة
  • معرف المهمة: عرض ID المهمة فوق كل نقطة
  • Bottom Sheet: عرض تفاصيل المهمة عند الضغط على النقطة

🔍 تحليل البيانات المطلوبة

من تحليل قاعدة البيانات:
  • جدول tasks: يحتوي على driver_id, status, customer_id
  • جدول tasks_points: يحتوي على latitude, longitude, type (pickup/delivery)
  • جدول drivers: يحتوي على longitude, altitude (latitude), last_seen_at

⚙️ الجدوى التقنية

✅ إمكانية التطبيق: عالية جداً

  • MapBox متوفر: المشروع يستخدم MapBox بالفعل في الـ Backend
  • APIs جاهزة: يوجد APIs لجلب المهام وتتبع السائقين
  • Dependencies موجودة: google_maps_flutter و geolocator متوفرة
  • البيانات متاحة: جميع البيانات المطلوبة موجودة في قاعدة البيانات

⚠️ التحديات المتوقعة

  • تحديث الموقع في الوقت الفعلي: يحتاج WebSocket أو Polling
  • أداء الخريطة: مع عدد كبير من النقاط
  • MapBox vs Google Maps: قد نحتاج لتغيير إلى MapBox Flutter
  • أيقونات مخصصة: تحتاج تصميم وتحسين

🛠️ المكدس التقني المطلوب

📱 Flutter Packages

  • mapbox_gl (بدلاً من google_maps)
  • geolocator (موجود)
  • permission_handler (موجود)
  • http (للـ APIs)

🌐 Backend APIs

  • GET /customer/tasks/active
  • GET /customer/tasks/{id}/details
  • GET /driver/{id}/location
  • WebSocket للتحديثات الفورية

🗺️ MapBox Integration

  • MapBox Access Token
  • Custom Markers
  • Clustering للنقاط المتقاربة
  • Real-time Updates

🎨 UI Components

  • Floating Action Buttons
  • Bottom Sheet
  • Custom Markers
  • Loading States

📝 خطة التطبيق

🚀 المرحلة الأولى: إعداد الأساسيات

  1. إضافة MapBox Flutter Package:
    dependencies: mapbox_gl: ^0.16.0 # Remove google_maps_flutter if not needed elsewhere
  2. إنشاء نماذج البيانات:
    • TaskMapData model
    • DriverLocation model
    • MapMarker model
  3. إعداد MapBox Token: في app_config.dart

🗺️ المرحلة الثانية: تطوير الخريطة

  1. إنشاء MapHomeScreen: شاشة رئيسية جديدة بالخريطة
  2. إضافة العناصر الطافية: اسم المستخدم والأيقونات
  3. تطبيق Custom Markers: نقاط زرقاء وأيقونات الشاحنات
  4. إضافة Labels: عرض ID المهمة فوق كل نقطة

📡 المرحلة الثالثة: ربط البيانات

  1. إنشاء MapService: لإدارة بيانات الخريطة
  2. تطوير APIs جديدة: لجلب المهام النشطة مع المواقع
  3. تطبيق Real-time Updates: تحديث المواقع كل 30 ثانية
  4. إضافة Bottom Sheet: لعرض تفاصيل المهام

🎨 المرحلة الرابعة: التحسينات والتفاعل

  1. تحسين الأداء: Clustering للنقاط المتقاربة
  2. إضافة Animations: للانتقالات والتحديثات
  3. تطبيق Error Handling: للحالات الاستثنائية
  4. اختبار شامل: على أجهزة مختلفة

🌐 APIs المطلوبة

📡 APIs جديدة مطلوبة

GET /api/customer/tasks/map-data
جلب المهام النشطة مع المواقع الجغرافية
GET /api/customer/drivers/locations
جلب مواقع السائقين للمهام المعينة
WebSocket: /ws/customer/map-updates
تحديثات فورية لمواقع السائقين والمهام

🔄 APIs موجودة يمكن استخدامها

  • /api/customer/tasks: لجلب قائمة المهام
  • /api/customer/tasks/{id}: لتفاصيل المهمة
  • /api/customer/tasks/{id}/track: لتتبع المهمة
