إصلاح خطأ retractOffer

الملف: app/Http/Controllers/admin/TasksAdsController.php

المشكلة: منطق خاطئ في إلغاء قبول العروض - يقوم بتعيين accepted = true بدلاً من false

// الكود الحالي (خطأ) Task_Offire::where('task_ad_id', $offer->ad_id)->update(['accepted' => true]); // الكود المصحح Task_Offire::where('task_ad_id', $offer->ad_id)->update(['accepted' => false]);

التأثير: يسبب مشاكل في إدارة العروض وقد يؤدي لقبول عروض متعددة

إصلاح التحقق من الصلاحيات

الملف: app/Http/Controllers/admin/TasksAdsController.php

المشكلة: استخدام user_id بدلاً من customer_id للمهام التي ينشئها العملاء

// الكود الحالي (خطأ) if ($offer->ad && $offer->ad->task && $offer->ad->task->user_id !== Auth::id()) // الكود المصحح if ($offer->ad && $offer->ad->task && (($offer->ad->task->customer_id && $offer->ad->task->customer_id !== Auth::id()) || ($offer->ad->task->user_id && $offer->ad->task->user_id !== Auth::id())))

التأثير: مشكلة أمنية - قد يسمح للمستخدمين بالوصول لإعلانات ليس لهم صلاحية عليها
