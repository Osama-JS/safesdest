هيكل النظام والمكونات

تحليل مفصل لبنية قاعدة البيانات والمكونات الأساسية للنظام

بنية قاعدة البيانات

📊 الجداول الأساسية (Core Tables)
users - المستخدمين الإداريين
id, name, email, phone, status, role_id, additional_data
customers - العملاء
id, name, email, phone, company_name, status, team_id
drivers - السائقين
id, name, phone, email, team_id, vehicle_size_id, online, free
teams - الفرق
id, name, address, commission_type, commission_value, is_public
🚚 جداول المهام (Task Tables)
tasks - المهام الرئيسية
id, status, total_price, commission, payment_method, customer_id, driver_id
tasks_points - نقاط المهام
id, type, contact_name, address, latitude, longitude, task_id
tasks_ads - إعلانات المهام
id, description, status, highest_price, lowest_price, task_id
tasks_offers - عروض السائقين
id, price, description, accepted, task_ad_id, driver_id
💰 الجداول المالية (Financial Tables)
wallets - المحافظ
id, user_type, debt_ceiling, status, customer_id, driver_id
wallet_transactions - المعاملات المالية
id, amount, transaction_type, description, status, wallet_id, task_id
⚙️ جداول الإعدادات (Settings Tables)
form_templates - قوالب النماذج
id, name, description, status
form_fields - حقول النماذج
id, name, type, required, form_template_id
pricing_templates - قوالب التسعير
id, name, description, status
geofences - المناطق الجغرافية
id, name, coordinates, status

العلاقات بين الجداول

🔗 العلاقات الأساسية
Users → Roles: belongsTo
كل مستخدم ينتمي لدور واحد
Drivers → Teams: belongsTo
كل سائق ينتمي لفريق واحد
Teams → Drivers: hasMany
كل فريق يحتوي على عدة سائقين
Tasks → Customer: belongsTo
كل مهمة تنتمي لعميل واحد
Tasks → Driver: belongsTo
كل مهمة مُعينة لسائق واحد
💰 العلاقات المالية
Wallets → Customer: belongsTo
كل محفظة تنتمي لعميل أو سائق
Wallets → Driver: belongsTo
محافظ منفصلة للسائقين
Wallet_Transactions → Wallet: belongsTo
كل معاملة تنتمي لمحفظة واحدة
Wallet_Transactions → Task: belongsTo (nullable)
المعاملات قد تكون مرتبطة بمهمة
Tasks → Wallet_Transactions: hasMany
كل مهمة قد تحتوي على عدة معاملات
