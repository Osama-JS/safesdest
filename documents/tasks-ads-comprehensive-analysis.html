تحليل شامل لنظام إعلانات المهام

فحص كامل لآلية Tasks Ads والتفاعل بين المستخدمين

تاريخ التحليل: 2024-12-02

ملخص النظام الحالي

المكونات الأساسية:
  • جدول tasks_ads: يحتوي على بيانات الإعلانات
  • جدول tasks_offers: يحتوي على عروض السائقين
  • 3 Controllers: للعملاء والسائقين والمدراء
  • Views متعددة: لعرض الإعلانات والعروض
  • JavaScript تفاعلي: لإدارة العروض
حالات الإعلان:
running الإعلان نشط ويقبل عروض
closed الإعلان مغلق بعد قبول عرض

أدوار المستخدمين

العملاء (Customers)
  • • عرض إعلاناتهم
  • • مراجعة العروض
  • • قبول/رفض العروض
  • • إغلاق الإعلانات
السائقين (Drivers)
  • • عرض الإعلانات المتاحة
  • • تقديم عروض
  • • تعديل العروض
  • • قبول المهام المعينة
المدراء (Admins)
  • • إدارة جميع الإعلانات
  • • مراجعة العروض
  • • قبول/رفض العروض
  • • إشراف عام

دورة حياة الإعلان

1
إنشاء المهمة كإعلان

عند إنشاء مهمة جديدة مع method = 0، يتم:

  • تعيين status = 'advertised'
  • تعيين pricing_type = 'manual'
  • تعيين total_price = 0
  • إنشاء سجل في tasks_ads
2
عرض الإعلان للسائقين

السائقون يرون الإعلانات بناءً على:

  • حجم المركبة المطابق
  • حالة الإعلان = 'running'
  • حالة المهمة = 'advertised'
3
تقديم العروض

السائقون يقدمون عروضهم مع:

  • السعر المقترح
  • وصف العرض
  • إمكانية التعديل
4
مراجعة وقبول العروض

صاحب المهمة (عميل/مدير) يقوم بـ:

  • مراجعة جميع العروض
  • قبول عرض واحد فقط
  • رفض باقي العروض تلقائياً
5
تعيين المهمة

عند قبول العرض يتم:

  • تعيين السائق للمهمة
  • تحديث سعر المهمة
  • تغيير حالة المهمة إلى 'assign'
  • إغلاق الإعلان (status = 'closed')

آلية إنشاء الإعلانات

شروط إنشاء الإعلان:
  • يجب أن يكون method = 0 في بيانات المهمة
  • لا يمكن تعيين سائق مسبقاً
  • يجب أن تكون مهمة واحدة فقط (vehicles_quantity = 1)
  • يجب تحديد أعلى وأقل سعر مقبول
// في TasksController عند إنشاء المهمة if ($taskData['method'] == 0) { $task['total_price'] = 0; $task['pricing_type'] = 'manual'; $task['status'] = 'advertised'; $ad = [ 'highest_price' => $req->max_price, 'lowest_price' => $req->min_price, 'description' => $req->note_price, ]; // إنشاء الإعلان $newTask->ad()->create($ad); }

المشاكل الحالية في النظام

مشاكل حرجة:
  • عدم وجود آلية إغلاق الإعلان: لا توجد طريقة لإغلاق الإعلان يدوياً
  • عدم وضوح ما يحدث بعد الإغلاق: لا توجد إجراءات محددة
  • عدم إدارة العروض المرفوضة: لا يتم إشعار السائقين
  • عدم وجود تاريخ انتهاء للإعلان: قد يبقى مفتوحاً إلى ما لا نهاية
  • عدم التحقق من توفر السائق: قد يكون مشغولاً بمهمة أخرى
مشاكل متوسطة:
  • عدم وجود نظام تقييم: لا يمكن تقييم العروض
  • عدم وجود تاريخ للعروض: لا يمكن معرفة متى قُدم العرض
  • عدم وجود حد أقصى للعروض: سائق واحد يمكنه تقديم عروض متعددة
  • عدم وجود إشعارات: لا يتم إشعار الأطراف بالتحديثات
  • عدم وجود سجل للتغييرات: لا يمكن تتبع تاريخ العروض
مشاكل في التصميم:
  • عدم وجود فلترة متقدمة: لا يمكن فلترة الإعلانات حسب المعايير
  • عدم وجود ترتيب للعروض: لا يتم ترتيب العروض حسب السعر
  • عدم وجود إحصائيات: لا توجد إحصائيات عن الإعلانات
  • عدم وجود تصدير: لا يمكن تصدير بيانات الإعلانات

أسئلة مهمة بحاجة لإجابة

ما يحدث بعد إغلاق الإعلان؟
  • • هل يتم حذف العروض المرفوضة؟
  • • هل يتم إشعار السائقين المرفوضين؟
  • • هل يمكن إعادة فتح الإعلان؟
  • • ما هو مصير البيانات؟
صلاحيات صاحب الإعلان
  • • هل يمكن تعديل الإعلان؟
  • • هل يمكن حذف الإعلان؟
  • • هل يمكن إغلاقه يدوياً؟
  • • هل يمكن رفض جميع العروض؟

التوصيات والتحسينات المقترحة

تحسينات عاجلة (أولوية عالية):
  • إضافة آلية إغلاق الإعلان يدوياً: زر لإغلاق الإعلان بدون قبول أي عرض
  • إضافة تاريخ انتهاء للإعلان: حقل expires_at في جدول tasks_ads
  • إصلاح منطق retractOffer: تصحيح الخطأ في إلغاء قبول العروض
  • إضافة نظام إشعارات: إشعار السائقين عند قبول/رفض عروضهم
  • تحسين التحقق من الصلاحيات: إصلاح التحقق من customer_id vs user_id
تحسينات متوسطة الأولوية:
  • إضافة حالات جديدة للإعلان: expired, cancelled, rejected
  • إضافة نظام تقييم العروض: تقييم من 1-5 نجوم
  • إضافة سجل تاريخ العروض: تتبع تعديلات العروض
  • إضافة فلترة متقدمة: فلترة حسب السعر، التاريخ، المنطقة
  • إضافة ترتيب العروض: ترتيب حسب السعر، التقييم، التاريخ
ميزات إضافية مقترحة:
  • نظام المزايدة: السماح بالمزايدة على العروض
  • إحصائيات شاملة: تقارير عن أداء الإعلانات
  • نظام التفضيلات: حفظ السائقين المفضلين
  • إشعارات فورية: إشعارات push للتحديثات
  • نظام التعليقات: تعليقات على العروض
