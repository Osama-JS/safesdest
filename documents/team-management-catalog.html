New Tables

team_task_assignments
id (bigint, primary key) team_id (bigint, FK → teams.id) task_id (bigint, FK → tasks.id) assigned_by (bigint, FK → users.id) assigned_at (timestamp) status (varchar) - pending, accepted, rejected, completed notes (text, nullable) created_at, updated_at (timestamps)
team_performance_logs
id (bigint, primary key) team_id (bigint, FK → teams.id) driver_id (bigint, FK → drivers.id) task_id (bigint, FK → tasks.id) performance_score (decimal 5,2) completion_time_minutes (integer) distance_traveled (decimal 8,2) completion_status (varchar) performance_metrics (jsonb) notes (text, nullable) created_at, updated_at (timestamps)

Team Management Routes

GET /admin/teams/{teamId}/management
teams.management.index → TeamManagementController@index

Main team management dashboard with statistics and activities

GET /admin/teams/{teamId}/management/drivers
teams.management.drivers → TeamManagementController@drivers

Advanced driver management page with interactive table

POST /admin/teams/{teamId}/management/drivers/{driverId}/status
teams.management.drivers.status → TeamManagementController@updateDriverStatus

Update driver status (available/busy/offline)

GET /admin/teams/{teamId}/management/tasks
teams.management.tasks → TeamManagementController@tasks

Team tasks management page

POST /admin/teams/{teamId}/management/settings
teams.management.settings → TeamManagementController@updateSettings

Update team settings (auto assignment, max tasks)

Task Assignment Routes

GET /admin/teams/{teamId}/assignment
teams.assignment.index → TeamTaskAssignmentController@index

Smart task assignment page

GET /admin/teams/{teamId}/assignment/available-tasks
teams.assignment.available-tasks → TeamTaskAssignmentController@getAvailableTasks

API to fetch available tasks for assignment with filtering

POST /admin/teams/{teamId}/assignment/assign-task
teams.assignment.assign-task → TeamTaskAssignmentController@assignTask

Assign single task to specific driver

POST /admin/teams/{teamId}/assignment/auto-assign
teams.assignment.auto-assign → TeamTaskAssignmentController@autoAssign

Smart automatic task assignment

TeamManagementController

index($teamId) - Main dashboard with statistics drivers($teamId) - Driver management page getDriversData($teamId) - API for drivers table updateDriverStatus($teamId, $driverId) - Update driver status tasks($teamId) - Team tasks page getTasksData($teamId) - API for tasks table updateSettings($teamId) - Update team settings performance($teamId) - Performance reports page

TeamTaskAssignmentController

index($teamId) - Task assignment page getAvailableTasks($teamId) - Get available tasks with filtering assignTask($teamId) - Assign single task to driver bulkAssign($teamId) - Bulk task assignment autoAssign($teamId) - Smart automatic assignment getAvailableDrivers($teamId) - Get available drivers performAutoAssignment($team) - Auto assignment algorithm

TeamPerformanceController

index($teamId) - Performance reports dashboard getDriversPerformance($teamId) - Drivers performance data getPerformanceLogsData($teamId) - Performance logs data exportReport($teamId) - Export reports (Excel, PDF, CSV)

TeamTaskAssignment Model

Relationships: - belongsTo(Teams::class, 'team_id') - belongsTo(Task::class, 'task_id') - belongsTo(User::class, 'assigned_by') Methods: - getStatusLabelAttribute() - Get status label - scopeByTeam($query, $teamId) - Filter by team - scopeByStatus($query, $status) - Filter by status

TeamPerformanceLog Model

Relationships: - belongsTo(Teams::class, 'team_id') - belongsTo(Driver::class, 'driver_id') - belongsTo(Task::class, 'task_id') Methods: - getPerformanceGradeAttribute() - Get performance grade - scopeByTeam($query, $teamId) - Filter by team - scopeByDriver($query, $driverId) - Filter by driver - scopeByDateRange($query, $from, $to) - Filter by date range
