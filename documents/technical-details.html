تغييرات قاعدة البيانات

ملاحظة مهمة:

لم يتم إجراء أي تغييرات على بنية قاعدة البيانات. جميع التحسينات تمت على مستوى التطبيق فقط.

📊 الجداول المستخدمة:
  • wallet_transactions: جدول المعاملات الرئيسي
  • wallets: جدول المحافظ
  • teams: جدول الفرق
  • drivers: جدول السائقين
  • tasks: جدول المهام
🔗 العلاقات المستخدمة:
  • Driver → Team: belongsTo relationship
  • Task → Driver: belongsTo relationship
  • Task → Customer: belongsTo relationship
  • Wallet_Transaction → Wallet: belongsTo relationship
  • Wallet_Transaction → User: belongsTo relationship

التقنيات والمكتبات المستخدمة

🖥️ Backend Technologies
  • Laravel Framework: PHP framework
  • Eloquent ORM: Database relationships
  • Carbon: Date manipulation
  • Database Transactions: Data consistency
  • Request Validation: Input validation
🎨 Frontend Technologies
  • jQuery: DOM manipulation
  • Bootstrap 5: UI framework
  • DataTables: Advanced tables
  • Select2: Enhanced dropdowns
  • DateRangePicker: Date selection
  • Moment.js: Date formatting
  • Mapbox GL JS: Interactive maps
