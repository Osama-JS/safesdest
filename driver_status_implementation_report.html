✅ بعد التحديث

  • عرض للقراءة فقط مع مؤشر "يتحكم به النظام"
  • استخدام driver?.free من البيانات
  • تصميم واضح يوضح أن النظام يتحكم

2. تحديث خدمة الموقع (LocationService):

safedest_driver/lib/services/location_service.dart
  • إزالة دوال التحكم: تم حذف setBusy() و setAvailable()
  • تحسين goOnline(): إزالة إرسال free=true
  • تحسين goOffline(): إزالة إرسال free=false
  • إضافة Timer: إرسال الموقع كل 3 دقائق
  • إدارة Timer: بدء/إيقاف Timer مع Online/Offline
// Timer جديد لإرسال الموقع كل 3 دقائق void _startLocationUpdateTimer() { _stopLocationUpdateTimer(); // Stop any existing timer _locationUpdateTimer = Timer.periodic( const Duration(minutes: 3), (timer) async { if (_isOnline && _currentPosition != null) { await _sendLocationUpdate(_currentPosition!); debugPrint('Location sent automatically (3-minute interval)'); } }, ); debugPrint('Location update timer started (3-minute intervals)'); }

3. تحديث Laravel API:

app/Http/Controllers/Api/DriverLocationController.php
  • إزالة validation: حذف 'free' من validation rules
  • منع تحديث free: عدم قبول free من الطلب
  • تحكم النظام: النظام يحدد free=false عند offline فقط
  • تحسين Logging: إضافة ملاحظة أن free يتحكم به النظام
// الكود الجديد - منع تحديث free من الخارج $validator = Validator::make($request->all(), [ 'online' => 'required|boolean', 'status' => 'nullable|string|in:available,busy,offline' // تم حذف 'free' => 'nullable|boolean' ]); // النظام يتحكم في free status if (!$request->online) { $updateData['free'] = false; } // Note: free status is now controlled by the system, not by driver input

🧪خطوات الاختبار

مطلوب: اختبار شامل للتأكد من عمل جميع الوظائف بشكل صحيح

🔍 اختبارات مطلوبة:

🌐 اختبار حالة الاتصال

  • تشغيل/إيقاف Online من Switch
  • التأكد من بدء تتبع الموقع عند Online
  • التأكد من إيقاف التتبع عند Offline

📍 اختبار تتبع الموقع

  • التأكد من إرسال الموقع كل 3 دقائق
  • فحص logs للتأكد من الإرسال
  • اختبار إيقاف الإرسال عند Offline

✅ اختبار حالة متاح للمهام

  • التأكد من عدم وجود أزرار للتحكم
  • التأكد من عرض "يتحكم به النظام"
  • فحص أن API لا يقبل تحديث free

🔄 اختبار التحديث التلقائي

  • التأكد من تحديث الحالة من الخادم
  • فحص عرض البيانات الصحيحة
  • اختبار refresh البيانات

📋 قائمة فحص سريعة:

  • Switch Online/Offline يعمل بشكل صحيح
  • لا توجد أزرار للتحكم في متاح/مشغول
  • يظهر نص "يتحكم به النظام" بوضوح
  • الموقع يُرسل كل 3 دقائق عند Online
  • التتبع يتوقف عند Offline
  • API لا يقبل تحديث free status
