🔍 خطوات الفحص اليومي

1

فحص المستخدمين النشطين

يقوم النظام بفحص جداول users, customers, drivers للمستخدمين بحالة active فقط.

// استعلام المستخدمين النشطين User::where('status', 'active')->whereNotNull('additional_data')->get() Customer::where('status', 'active')->whereNotNull('additional_data')->get() Driver::where('status', 'active')->whereNotNull('additional_data')->with('team.users.user')->get()
2

تحليل البيانات الإضافية

فحص حقل additional_data للبحث عن الحقول من نوع file_expiration_date التي تحتوي على تاريخ انتهاء.

// بنية البيانات المطلوبة { "field_name": { "label": "رخصة القيادة", "value": "files/license.pdf", "expiration": "2024-12-31", "type": "file_expiration_date" } }
3

فحص تواريخ الانتهاء

التحقق من الملفات التي انتهت صلاحيتها أو ستنتهي خلال يوم واحد من تاريخ اليوم.

// شرط الفحص $expirationDate = Carbon::parse($fieldData['expiration']); $today = now()->startOfDay(); if ($expirationDate->lte($today->copy()->addDay())) { // الملف منتهي أو سينتهي خلال يوم }
4

منع التكرار

التحقق من عدم إرسال تنبيه لنفس الملف في نفس اليوم باستخدام مفتاح فريد.

// فحص التكرار $existingNotification = FileExpirationNotification::where([ 'user_type' => $userType, 'user_id' => $user->id, 'field_name' => $fieldName, 'notification_sent_date' => today() ])->first();
5

تحديد المستلمين

إنشاء قائمة المستلمين: المستخدم نفسه + مدير الفريق (للسائقين) + إيميل المنصة.

$recipients = [$user->email]; // إضافة مدير الفريق للسائقين if ($userType === 'driver' && $user->team_id) { $teamManagers = $user->team->users()->with('user')->get(); foreach ($teamManagers as $teamUser) { if ($teamUser->user && $teamUser->user->status === 'active') { $recipients[] = $teamUser->user->email; } } } // إضافة إيميل المنصة $recipients[] = config('app.platform_notification_email');
6

إرسال التنبيهات

إرسال إيميلات مخصصة لكل مستلم باستخدام قالب file-expiration-notification.

$this->emailService->sendWithTemplate( 'file-expiration-notification', $email, 'تنبيه: انتهاء صلاحية الملف - ' . $fieldData['label'], [ 'user_name' => $user->name, 'user_type' => $this->getUserTypeInArabic($userType), 'field_label' => $fieldData['label'], 'expiration_date' => $expirationDate->format('Y-m-d'), 'days_remaining' => max(0, $daysBeforeExpiration), 'is_expired' => $daysBeforeExpiration < 0, 'action_url' => $this->getUpdateUrl($userType) ] );
7

تسجيل التنبيه

حفظ تفاصيل التنبيه في جدول file_expiration_notifications لمنع التكرار والمتابعة.

FileExpirationNotification::createSafely([ 'user_type' => $userType, 'user_id' => $user->id, 'field_name' => $fieldName, 'field_label' => $fieldData['label'], 'file_path' => $fieldData['value'] ?? '', 'expiration_date' => $expirationDate, 'notification_sent_date' => today(), 'days_before_expiration' => $daysBeforeExpiration, 'recipients' => $recipients ]);
8

تعليق الحسابات

فحص التنبيهات المرسلة قبل 3 أيام أو أكثر وتعليق الحسابات التي لم تحدث ملفاتها.

// البحث عن التنبيهات القديمة $notificationsToSuspend = FileExpirationNotification::where('status', 'sent') ->where('notification_sent_date', '<=', now()->subDays(3)->toDateString()) ->get(); foreach ($notificationsToSuspend as $notification) { $user = $notification->user(); if ($user && $user->status === 'active') { // تعليق الحساب $user->update(['status' => 'inactive']); $notification->update(['status' => 'account_suspended']); // إرسال إشعار التعليق $this->sendAccountSuspensionNotification($user, $notification); } }
💻 أوامر التشغيل والإدارة
✅ الأمر الرئيسي: php artisan files:check-expirations - يمكن تشغيله يدوياً في أي وقت للفحص الفوري

🔍 الفحص الأساسي

# فحص شامل مع إرسال التنبيهات php artisan files:check-expirations # النتيجة المتوقعة: ✅ تم إكمال فحص الملفات بنجاح! المستخدمين المفحوصين: 150 العملاء المفحوصين: 89 السائقين المفحوصين: 234 التنبيهات المرسلة: 12 الحسابات المعلقة: 3

📊 عرض الإحصائيات

# عرض إحصائيات مفصلة فقط php artisan files:check-expirations --stats # النتيجة المتوقعة: 📊 إحصائيات النظام: 👥 المستخدمين النشطين: مستخدمي النظام: 150 العملاء: 89 السائقين: 234 🔔 تنبيهات اليوم: إجمالي التنبيهات: 12 الملفات المنتهية: 8 الملفات ستنتهي قريباً: 4

🧪 التشغيل التجريبي

# تشغيل تجريبي بدون إرسال إيميلات php artisan files:check-expirations --dry-run # تشغيل تجريبي مع تفاصيل إضافية php artisan files:check-expirations --dry-run --verbose # فائدة: اختبار النظام بأمان قبل التشغيل الفعلي

🎯 فحص نوع محدد

# فحص المستخدمين فقط php artisan files:check-expirations --user-type=user # فحص العملاء فقط php artisan files:check-expirations --user-type=customer # فحص السائقين فقط php artisan files:check-expirations --user-type=driver

⚙️ أوامر الإدارة والصيانة

📅 فحص الجدولة

# عرض جميع المهام المجدولة php artisan schedule:list # تشغيل الجدولة يدوياً (للاختبار) php artisan schedule:run # مراقبة الجدولة في الوقت الفعلي php artisan schedule:work

🗄️ إدارة قاعدة البيانات

# تشغيل Migration الجديد php artisan migrate --path=database/migrations/2025_07_24_000001_create_file_expiration_notifications_table.php # فحص حالة Migrations php artisan migrate:status # التراجع عن Migration (إذا لزم الأمر) php artisan migrate:rollback --step=1

🔄 إدارة الطوابير

# تشغيل معالج الطوابير php artisan queue:work --verbose # مراقبة الطوابير المعلقة php artisan queue:monitor # إعادة تشغيل الطوابير الفاشلة php artisan queue:retry all

🧹 تنظيف النظام

# تنظيف السجلات القديمة يدوياً php artisan db:query "DELETE FROM file_expiration_notifications WHERE status = 'sent' AND created_at < DATE_SUB(NOW(), INTERVAL 30 DAY)" # تنظيف ملفات السجلات php artisan log:clear # تحسين قاعدة البيانات php artisan optimize:clear
⚠️ تحذير مهم: استخدم الأوامر التجريبية --dry-run دائماً قبل التشغيل الفعلي في بيئة الإنتاج لتجنب أي مشاكل غير متوقعة.

📋 ملفات السجلات

📄 سجل Laravel الرئيسي

# مسار الملف storage/logs/laravel.log # مراقبة السجل في الوقت الفعلي tail -f storage/logs/laravel.log # البحث عن سجلات النظام grep "File expiration" storage/logs/laravel.log # أمثلة السجلات: [2025-07-24 10:00:01] INFO: Starting file expiration check process [2025-07-24 10:00:15] INFO: Checked 150 users, 12 had expired files [2025-07-24 10:00:20] INFO: File expiration notification sent successfully [2025-07-24 10:00:25] WARNING: Account suspended due to expired file

📊 سجل الإحصائيات

# استعلام الإحصائيات من قاعدة البيانات SELECT DATE(created_at) as date, user_type, COUNT(*) as total_notifications, COUNT(CASE WHEN status = 'sent' THEN 1 END) as sent, COUNT(CASE WHEN status = 'account_suspended' THEN 1 END) as suspended FROM file_expiration_notifications WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY) GROUP BY DATE(created_at), user_type ORDER BY date DESC;

# المشكلة: Command "files:check-expirations" is not defined # الحل: 1. تأكد من وجود الملف: app/Console/Commands/CheckFileExpirations.php 2. تنظيف الكاش: php artisan config:clear php artisan cache:clear php artisan optimize:clear 3. إعادة تحميل الأوامر: php artisan list | grep files

# المشكلة: Connection could not be established with host # التشخيص: php artisan tinker Mail::raw('Test', function($msg) { $msg->to('test@example.com')->subject('Test'); }); # الحل: 1. فحص إعدادات SMTP في .env 2. اختبار الاتصال 3. إعادة تشغيل الطوابير

# المشكلة: Table 'file_expiration_notifications' doesn't exist # الحل: 1. تشغيل Migration: php artisan migrate --path=database/migrations/2025_07_24_000001_create_file_expiration_notifications_table.php 2. فحص حالة Migration: php artisan migrate:status 3. فحص الجدول: DESCRIBE file_expiration_notifications;
