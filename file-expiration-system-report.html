🔍 تحليل النظام الحالي

✅ نظام الإيميلات الحالي

  • EmailNotificationService: خدمة شاملة مع دعم القوالب
  • SendEmailNotificationJob: نظام طوابير مع إعادة المحاولة
  • EmailNotificationLog: تسجيل شامل لحالة الإيميلات
  • القوالب المتاحة: notification, welcome, task-assigned

📊 بنية البيانات الإضافية

{ "field_name": { "label": "رخصة القيادة", "value": "path/to/file.pdf", "expiration": "2024-12-31", "type": "file_expiration_date" } }

🎯 الجداول المستهدفة

  • users: additional_data + status (active/inactive/deleted/pending)
  • customers: additional_data + status (active/verified/blocked)
  • drivers: additional_data + status + team_id

🔗 العلاقات المهمة

  • Driver → Team: علاقة belongsTo
  • Team → Users: علاقة hasMany عبر user_has_teams
  • Form Templates: تحديد نوع الحقول

🗄️ جدول التنبيهات الجديد

Schema::create('file_expiration_notifications', function (Blueprint $table) { $table->id(); $table->string('user_type'); // 'user', 'customer', 'driver' $table->unsignedBigInteger('user_id'); $table->string('field_name'); // اسم الحقل $table->string('field_label'); // تسمية الحقل $table->string('file_path'); // مسار الملف $table->date('expiration_date'); // تاريخ الانتهاء $table->date('notification_sent_date'); // تاريخ الإرسال $table->integer('days_before_expiration'); $table->enum('status', ['sent', 'account_suspended']); $table->json('recipients')->nullable(); $table->timestamps(); });

⏰ الجدولة والتوقيت

🕙 التوقيت المقترح

  • التشغيل اليومي: الساعة 10:00 صباحاً
  • المنطقة الزمنية: Asia/Riyadh
  • عدم التداخل: withoutOverlapping()
  • التشغيل في الخلفية: runInBackground()
  • تقارير الأخطاء: emailOutputOnFailure()

🔒 آلية منع التكرار

  • فحص يومي: التحقق من التنبيهات المرسلة اليوم
  • مفتاح فريد: (user_type, user_id, field_name, date)
  • تسجيل شامل: حفظ جميع التفاصيل
  • منع الإزعاج: تنبيه واحد فقط لكل ملف يومياً

⚡ إعدادات الأداء

// في app/Console/Kernel.php $schedule->command('files:check-expirations') ->dailyAt('10:00') ->timezone('Asia/Riyadh') ->withoutOverlapping() ->runInBackground() ->emailOutputOnFailure(config('app.admin_email'));

🔄 آلية العمل التفصيلية
🎯 الهدف الأساسي: فحص يومي شامل للملفات منتهية الصلاحية مع إرسال تنبيهات ذكية وتعليق الحسابات المهملة

1️⃣ مرحلة الفحص اليومي (10:00 صباحاً)

1
فحص المستخدمين النشطين
البحث في جداول users, customers, drivers للمستخدمين بحالة 'active'
2
تحليل البيانات الإضافية
فحص additional_data للبحث عن حقول نوع 'file_expiration_date'
3
فحص تواريخ الانتهاء
التحقق من الملفات منتهية الصلاحية أو التي ستنتهي خلال يوم واحد
4
منع التكرار
التحقق من عدم إرسال تنبيه لنفس الملف في نفس اليوم
5
تحديد المستلمين
المستخدم + مدير الفريق (للسائقين) + إيميل المنصة
6
إرسال التنبيهات
إرسال إيميلات مخصصة لكل مستلم مع تفاصيل الملف
7
تسجيل التنبيه
حفظ تفاصيل التنبيه في قاعدة البيانات لمنع التكرار

2️⃣ مرحلة تعليق الحسابات (بعد 3 أيام)

1
البحث عن التنبيهات القديمة
العثور على التنبيهات المرسلة قبل 3 أيام أو أكثر
2
فحص حالة المستخدم
التأكد من أن المستخدم لا يزال نشطاً ولم يحدث الملف
3
تعليق الحساب
تغيير حالة المستخدم إلى 'inactive'
4
إرسال إشعار التعليق
إرسال إيميل إشعار بتعليق الحساب مع تعليمات الإعادة
5
تحديث حالة التنبيه
تغيير حالة التنبيه إلى 'account_suspended'

👥 المستلمون للتنبيهات

  • المستخدم نفسه: دائماً (إيميل أساسي)
  • مدير الفريق: للسائقين فقط إذا كان ينتمي لفريق
  • إيميل المنصة: دائماً للمراقبة والمتابعة
  • إزالة التكرارات: تلقائياً من قائمة المستلمين

⚠️ شروط الفحص

  • الحالة النشطة: فقط المستخدمين بحالة 'active'
  • وجود البيانات: additional_data غير فارغة
  • نوع الحقل: 'file_expiration_date' فقط
  • وجود تاريخ الانتهاء: حقل expiration مملوء

📈 مؤشرات الأداء

  • عدد المستخدمين المفحوصين: تقرير يومي
  • عدد التنبيهات المرسلة: إحصائية مفصلة
  • عدد الحسابات المعلقة: متابعة دقيقة
  • معدل نجاح الإرسال: مراقبة مستمرة

-- إدراج بيانات اختبار للمستخدمين UPDATE users SET additional_data = '[ { "driving_license": { "label": "رخصة القيادة", "value": "files/license.pdf", "expiration": "2024-07-25", "type": "file_expiration_date" } } ]' WHERE id = 1;

⚠️ سيناريوهات الاختبار

  • ملف منتهي الصلاحية: تاريخ أمس
  • ملف سينتهي اليوم: تاريخ اليوم
  • ملف سينتهي غداً: تاريخ الغد
  • مستخدم غير نشط: status != 'active'
  • سائق بدون فريق: team_id = null
  • سائق مع فريق: team_id موجود
