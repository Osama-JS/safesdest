🔐 المصادقة والأمان
  • تسجيل الدخول الآمن: باستخدام Laravel Sanctum
  • حفظ البيانات المشفرة: Flutter Secure Storage
  • تجديد الرموز التلقائي: Token refresh mechanism
📋 إدارة المهام
  • عرض المهام المتاحة: قائمة تفاعلية مع التفاصيل
  • قبول ورفض المهام: واجهة سهلة للتفاعل
  • تتبع حالة المهام: تحديثات فورية
  • سجل المهام: تاريخ المهام المكتملة
💰 إدارة المحفظة
  • عرض الرصيد: الرصيد الحالي والمعلق
  • سجل المعاملات: تفاصيل جميع المعاملات
  • إحصائيات الأرباح: رسوم بيانية وتقارير
📍 تتبع الموقع
  • تتبع الموقع المباشر: GPS عالي الدقة

⚙️ ملف الإعدادات الرئيسي (app_config.dart)

🎯 الغرض: يحتوي على جميع الإعدادات الثابتة للتطبيق مثل URLs، المفاتيح، والقيم الافتراضية.
🔧 الإعدادات المتاحة
  • baseUrl: رابط API الأساسي
  • API Endpoints: جميع نقاط النهاية
  • Storage Keys: مفاتيح التخزين المحلي
  • Location Settings: إعدادات تتبع الموقع
  • UI Settings: إعدادات الواجهة
  • Colors: ألوان التطبيق (Red Theme)
// مثال على استخدام الإعدادات class AppConfig { static const String baseUrl = 'http://192.168.0.186/safedestsss/public/api'; static const String appName = 'SafeDests Driver'; // API Endpoints static const String loginEndpoint = '/driver/login'; static const String tasksEndpoint = '/driver/tasks'; // Storage Keys static const String tokenKey = 'auth_token'; static const String driverDataKey = 'driver_data'; // Helper Methods static String getApiUrl(String endpoint) { return '$baseUrl$endpoint'; } }

🔧 4. الخدمات وربط APIs

🌐 خدمة API الأساسية (ApiService)

⚡ api_service.dart

lib/services/api_service.dart

الوظيفة: الخدمة الأساسية للتواصل مع APIs، تدير المصادقة، الطلبات، ومعالجة الأخطاء.

🔑 الوظائف الرئيسية
  • get<T>(): طلبات GET مع معالجة الاستجابة
  • post<T>(): طلبات POST مع إرسال البيانات
  • put<T>(): طلبات PUT للتحديث
  • delete<T>(): طلبات DELETE للحذف
  • setAuthToken(): حفظ رمز المصادقة
  • refreshToken(): تجديد الرمز
// مثال على استخدام ApiService final response = await _apiService.get<Driver>( AppConfig.profileEndpoint, fromJson: (data) => Driver.fromJson(data['driver']), ); if (response.isSuccess && response.data != null) { // معالجة البيانات المستلمة final driver = response.data!; print('Driver name: ${driver.name}'); }

📋 خدمة المهام (TaskService)

الوظيفة: إدارة جميع عمليات المهام من جلب القائمة إلى تحديث الحالة.

📊 العمليات المتاحة
  • getTasks(): جلب قائمة المهام مع التصفح
  • getTaskDetails(): تفاصيل مهمة محددة
  • acceptTask(): قبول مهمة
  • rejectTask(): رفض مهمة
  • updateTaskStatus(): تحديث حالة المهمة
  • getTaskHistory(): سجل المهام المكتملة
// مثال على قبول مهمة Future<ApiResponse<Task>> acceptTask(int taskId) async { final response = await _apiService.post<Task>( AppConfig.getTaskEndpoint(taskId, 'accept'), fromJson: (data) => Task.fromJson(data['task']), ); if (response.isSuccess) { // تحديث القائمة المحلية await getTasks(refresh: true); notifyListeners(); } return response; }

📍 خدمة الموقع (LocationService)

🗺️ location_service.dart

lib/services/location_service.dart

الوظيفة: تتبع موقع السائق وإرسال التحديثات للخادم.

📡 وظائف التتبع
  • getCurrentLocation(): الحصول على الموقع الحالي
  • startLocationTracking(): بدء التتبع التلقائي
  • stopLocationTracking(): إيقاف التتبع
  • updateLocationToServer(): إرسال الموقع للخادم
  • updateDriverStatus(): تحديث حالة السائق
  • getCurrentStatus(): جلب الحالة الحالية
⚙️ إعدادات التتبع:
  • فترة التحديث: 30 ثانية (قابلة للتخصيص)
  • دقة الموقع: GPS عالي الدقة
  • المسافة الدنيا: 10 متر لتوفير البطارية
  • العمل في الخلفية: مدعوم
