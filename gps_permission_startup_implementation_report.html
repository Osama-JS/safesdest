⚙التنفيذ المطبق

تم بنجاح: إضافة طلب صلاحية GPS تلقائياً في SplashScreen مع تبسيط معالجة الأخطاء

1. إضافة دالة طلب الصلاحية في LocationService:

safedest_driver/lib/services/location_service.dart
// Request GPS permission only (for app startup) Future requestGPSPermissionOnly() async { try { debugPrint('🔍 Requesting GPS permission only...'); final hasPermission = await _requestLocationPermission(); if (hasPermission) { debugPrint('✅ GPS permission granted'); return true; } else { debugPrint('❌ GPS permission denied'); return false; } } catch (e) { debugPrint('💥 GPS permission request error: $e'); return false; } }

2. تحديث SplashScreen لطلب الصلاحية:

safedest_driver/lib/screens/splash_screen.dart
// في _initializeApp() await locationService.initialize(); debugPrint('SplashScreen: LocationService initialized'); // Request GPS permission immediately after LocationService initialization debugPrint('SplashScreen: Requesting GPS permission...'); await _requestGPSPermission(locationService); // انتظار مدة الـ Splash debugPrint('SplashScreen: Waiting for splash duration...');
// Request GPS permission during app startup Future _requestGPSPermission(LocationService locationService) async { try { debugPrint('🔍 SplashScreen: Requesting GPS permission...'); // Request permission only (no location sending) final hasPermission = await locationService.requestGPSPermissionOnly(); if (hasPermission) { debugPrint('✅ SplashScreen: GPS permission granted successfully'); } else { debugPrint('⚠️ SplashScreen: GPS permission denied or unavailable'); // Don't show error dialog, just log the issue } } catch (e) { debugPrint('💥 SplashScreen: GPS permission request error: $e'); // Don't show error dialog, just log the error } }

🧪خطوات الاختبار

للاختبار: تأكد من اختبار السيناريوهات المختلفة لطلب الصلاحية

📋 سيناريوهات الاختبار:

1️⃣ تطبيق جديد

  • تثبيت التطبيق لأول مرة
  • فتح التطبيق
  • يجب أن يطلب صلاحية GPS
  • فحص logs للتأكد

2️⃣ صلاحية ممنوحة مسبقاً

  • التطبيق له صلاحية GPS
  • فتح التطبيق
  • يجب أن يتخطى طلب الصلاحية
  • فحص logs للتأكد

3️⃣ رفض الصلاحية

  • رفض صلاحية GPS
  • التطبيق يجب أن يستمر
  • لا يجب عرض dialog خطأ
  • فحص logs للتأكد

4️⃣ اختبار زر الموقع

  • الضغط على زر إرسال الموقع
  • في حالة الخطأ: SnackBar بسيط
  • لا يجب عرض dialog معقد
  • رسالة خطأ واضحة

✅ ما يجب ملاحظته:

  • طلب تلقائي: الصلاحية تُطلب عند بدء التطبيق
  • Logs واضحة: رسائل debug تظهر حالة الصلاحية
  • لا dialog معقد: فقط SnackBar بسيط للأخطاء
  • استمرارية التطبيق: التطبيق يعمل حتى لو رُفضت الصلاحية
