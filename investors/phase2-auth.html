المصادقة ولوحة تحكم المستثمر

تخصيص تدفق تسجيل الدخول لتوجيه المستثمرين إلى لوحة التحكم الخاصة بهم، مع منع وصولهم إلى لوحة Admin.

🔄 تدفق تسجيل الدخول الجديد

المنطق الجديد في Auth Login

سيتم تعديل LoginController الحالي (في app/Http/Controllers/Auth/) لإضافة منطق التوجيه بعد نجاح تسجيل الدخول.

👤 المستخدم يدخل بيانات الدخول في صفحة Admin Login
↓
🔍 التحقق من صحة البيانات (Validation)
↓
✅ نجح تسجيل الدخول — جلب بيانات المستخدم
↓
❓ هل المستخدم مستثمر؟ (investor === true)
↓
✅ نعم
توجيه إلى
/investor/dashboard
❌ لا
توجيه إلى
/admin/dashboard
// في AuthenticatedSessionController أو LoginController // بعد نجاح المصادقة: protected function authenticated(Request $request, $user) { if ($user->investor) { return redirect()->route('investor.dashboard'); } return redirect()->intended(route('dashboard')); }

🛡️ Middleware الحماية

InvestorMiddleware.php

يتحقق من أن المستخدم الحالي هو مستثمر. يُستخدم لحماية routes لوحة تحكم المستثمر.

class InvestorMiddleware { public function handle(Request $request, Closure $next) { if (!auth()->check() || !auth()->user()->investor) { return redirect()->route('login') ->with('error', 'غير مصرح بالوصول'); } return $next($request); } }

BlockInvestorMiddleware.php

يمنع المستثمرين من الوصول إلى لوحة Admin. يُضاف إلى route group الخاص بالـ Admin.

class BlockInvestorMiddleware { public function handle(Request $request, Closure $next) { if (auth()->check() && auth()->user()->investor) { return redirect()->route('investor.dashboard') ->with('error', 'يرجى استخدام لوحة تحكم المستثمر'); } return $next($request); } }

تسجيل الـ Middleware في Kernel.php

// في app/Http/Kernel.php protected $routeMiddleware = [ // ... الموجود 'investor' => \App\Http\Middleware\InvestorMiddleware::class, 'block.investor' => \App\Http\Middleware\BlockInvestorMiddleware::class, ];

🗺️ Routes لوحة تحكم المستثمر

تعريف Routes في web.php

// في routes/web.php // حماية لوحة Admin من المستثمرين Route::middleware(['auth', 'block.investor'])->prefix('admin')->group(function() { // ... routes الأدمن الموجودة }); // لوحة تحكم المستثمر Route::middleware(['auth', 'investor']) ->prefix('investor') ->name('investor.') ->group(function() { Route::get('dashboard', [InvestorDashboardController::class, 'index']) ->name('dashboard'); // محفظة الاستثمار Route::get('investment-wallet', [InvestorWalletController::class, 'investmentWallet']) ->name('investment-wallet'); // المحفظة الشخصية (العمولات) Route::get('personal-wallet', [InvestorWalletController::class, 'personalWallet']) ->name('personal-wallet'); // دفع المهام (للمستثمر بالمهام فقط) Route::get('task-payment', [InvestorTaskPaymentController::class, 'index']) ->name('task-payment'); Route::post('task-payment/{task}', [InvestorTaskPaymentController::class, 'pay']) ->name('task-payment.pay'); // المهام المدفوعة Route::get('paid-tasks', [InvestorTaskPaymentController::class, 'paidTasks']) ->name('paid-tasks'); // الملف الشخصي Route::get('profile', [InvestorProfileController::class, 'show']) ->name('profile'); Route::put('profile', [InvestorProfileController::class, 'update']) ->name('profile.update'); Route::put('password', [InvestorProfileController::class, 'updatePassword']) ->name('password.update'); });

القائمة الجانبية حسب نوع الاستثمار

تتغير عناصر القائمة الجانبية بناءً على نوع العقد النشط للمستثمر:

مستثمر بالمهام (task_investment):

📊 لوحة التحكم
💼 محفظة الاستثمار
👛 محفظتي الشخصية
💳 دفع المهام
📋 المهام المدفوعة
👤 الملف الشخصي
🔑 تغيير كلمة المرور

مستثمر عام (general_investment):

📊 لوحة التحكم
💼 محفظة الاستثمار
👛 محفظتي الشخصية
📋 المهام المدفوعة
👤 الملف الشخصي
🔑 تغيير كلمة المرور
💡

صفحة "دفع المهام" تظهر فقط للمستثمر بالمهام (task_investment). المستثمر العام لا يتحكم في دفع المهام بنفسه.

✅ قائمة مهام التنفيذ

  • إنشاء InvestorMiddleware.php في app/Http/Middleware
  • إنشاء BlockInvestorMiddleware.php في app/Http/Middleware
  • تسجيل الـ Middleware في Kernel.php
  • تعديل LoginController لإضافة منطق التوجيه بعد الدخول
  • إضافة block.investor middleware إلى Route Group الأدمن
  • إنشاء Route Group الخاص بالمستثمر في web.php
  • إنشاء InvestorDashboardController.php
  • إنشاء InvestorWalletController.php
  • إنشاء InvestorTaskPaymentController.php
  • إنشاء InvestorProfileController.php
  • إنشاء Layout الخاص بلوحة تحكم المستثمر (Blade)
  • إنشاء القائمة الجانبية الديناميكية حسب نوع العقد
