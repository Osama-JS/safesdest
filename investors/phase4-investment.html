💰 المرحلة الرابعة

منطق الاستثمار والعمولات

القلب النابض للنظام — آليات الدفع، حساب العمولات التلقائي، وتسوية المحافظ بشكل دقيق ومتكامل.

⚖️ مقارنة نوعي الاستثمار

🎯 الاستثمار بالمهام (task_investment)

  • المستثمر يرى المهام المخصصة له ويختار ما يدفعه
  • الدفع يدوي بالكامل من لوحة تحكم المستثمر
  • يمكن تخصيص: عملاء محددين أو حد أدنى للعمولة
  • المهمة يجب أن تكون: غير مقفلة، غير مدفوعة من مستثمر
  • العمولة تُحسب وتُسجَّل في المحفظة الشخصية فور الدفع
  • العمولة من عمولة المنصة الكلية (وليس من قيمة المهمة)

🌐 الاستثمار العام (general_investment)

  • Admin يتحكم في ربط المهام بهذا المستثمر
  • لا تخصيص لعملاء محددين أو حد للعمولة
  • العمولة تُحتسب على جميع المهام التي يدفعها
  • Admin يختار أي مستثمر عام يدفع أي مهمة
  • الدفع يُسجَّل في محفظة الاستثمار كخصم
  • العمولة تُسجَّل في المحفظة الشخصية للمستثمر تلقائياً

🎯 آلية الاستثمار بالمهام — التدفق الكامل

منطق فلترة المهام المعروضة للمستثمر

عند فتح صفحة "دفع المهام"، يجلب النظام المهام المؤهلة فقط بناءً على إعدادات عقد المستثمر.

// InvestorTaskPaymentController@index public function index() { $investor = auth()->user(); $contract = $investor->activeInvestmentContract; if (!$contract || $contract->contract_type !== 'task_investment') { return abort(403); } $query = Task::availableForInvestorPayment() ->with(['customer', 'pickup', 'delivery', 'ad']); // فلتر العملاء المخصصين if (!empty($contract->filter_customer_ids)) { $query->whereIn('customer_id', $contract->filter_customer_ids); } // فلتر الحد الأدنى للعمولة if ($contract->min_commission_threshold > 0) { $query->whereHas('ad', function($q) use ($contract) { $q->where('commission', '>=', $contract->min_commission_threshold); }); } $tasks = $query->latest()->paginate(20); $walletBalance = $investor->investorWallet->balance; return view('investor.task-payment', compact('tasks', 'contract', 'walletBalance')); }

عملية الدفع على مهمة — التدفق الكامل

TRIGGER المستثمر يضغط "دفع" على مهمة محددة
CHECK التحقق: هل رصيد محفظة الاستثمار ≥ قيمة المهمة؟
CHECK التحقق: هل المهمة لا تزال مؤهلة؟ (غير مقفلة، لم يدفعها مستثمر آخر)
ACTION خصم قيمة المهمة من investor_wallet — تسجيل transaction بنوع debit
ACTION تحديث tasks: investor_id = المستثمر، investor_payment_status = 'paid'
COMMISSION حساب عمولة المستثمر من عمولة المنصة (commission في tasks_ads)
COMMISSION إيداع العمولة في user_wallets (المحفظة الشخصية) — تسجيل UserWalletTransaction
// InvestorTaskPaymentController@pay public function pay(Request $request, Task $task) { $investor = auth()->user(); $contract = $investor->activeInvestmentContract; DB::transaction(function() use ($investor, $task, $contract) { $investorWallet = $investor->investorWallet; $taskPrice = $task->total_price; // 1. التحقق من الرصيد الكافي if ($investorWallet->balance < $taskPrice) { throw new \Exception('رصيد غير كافٍ في محفظة الاستثمار'); } // 2. التحقق من أهلية المهمة if ($task->investor_payment_status !== 'none' || $task->closed) { throw new \Exception('هذه المهمة غير متاحة للدفع'); } // 3. خصم من محفظة الاستثمار $newBalance = $investorWallet->balance - $taskPrice; InvestorWalletTransaction::create([ 'investor_wallet_id' => $investorWallet->id, 'task_id' => $task->id, 'transaction_type' => 'debit', 'amount' => $taskPrice, 'description' => "دفع قيمة المهمة #{$task->id}", 'performed_by' => $investor->id, 'balance_after' => $newBalance, ]); // 4. تحديث حالة المهمة $task->update([ 'investor_id' => $investor->id, 'investor_payment_status' => 'paid', ]); // 5. حساب وتسجيل العمولة في المحفظة الشخصية if ($task->ad) { $platformCommission = $task->ad->commission; $investorCommission = $contract->commission_type === 'percentage' ? ($platformCommission * $contract->commission_value / 100) : $contract->commission_value; $personalWallet = $investor->userWallet; $personalBalance = $personalWallet->balance + $investorCommission; UserWalletTransaction::create([ 'user_wallet_id' => $personalWallet->id, 'task_id' => $task->id, 'transaction_type' => 'credit', 'amount' => $investorCommission, 'description' => "عمولة المهمة #{$task->id}", 'balance_after' => $personalBalance, ]); } }); return back()->with('success', 'تم دفع قيمة المهمة وتسجيل عمولتك بنجاح'); }

🌐 آلية الاستثمار العام — دفع Admin

تدفق دفع المهمة من Admin للمستثمر العام

في لوحة Admin عند إدارة المدفوعات، يظهر خيار "الدفع من محفظة مستثمر عام". عند اختياره يتم الربط بالمستثمر المناسب.

// في PaymentController أو TaskController@payFromInvestor public function payFromGeneralInvestor(Request $request, Task $task) { $request->validate([ 'investor_id' => 'required|exists:users,id', ]); $investor = User::where('id', $request->investor_id) ->where('investor', true) ->firstOrFail(); $contract = $investor->activeInvestmentContract; if (!$contract || $contract->contract_type !== 'general_investment') { return back()->with('error', 'هذا المستثمر ليس من نوع استثمار عام'); } // نفس منطق الخصم وتسجيل العمولة $this->processInvestorPayment($investor, $task, $contract); return back()->with('success', 'تم ربط المهمة بالمستثمر وتسجيل العمولة'); }
💡

يتم استخراج قائمة المستثمرين العامين في نافذة دفع المهمة لتسهيل اختيار Admin للمستثمر المناسب، مع عرض رصيد كل مستثمر في الـ dropdown.

⚠️ نقاط حرجة يجب مراعاتها

🔒 الحماية من التعارض (Race Conditions)

يجب استخدام DB::transaction مع lockForUpdate لمنع دفع نفس المهمة من مستثمرين في نفس الوقت:

$task = Task::lockForUpdate()->findOrFail($taskId); if ($task->investor_payment_status !== 'none') { throw new \Exception('المهمة محجوزة'); }

💡 حساب رصيد المحفظة

الرصيد يُحسب دائماً من مجموع الـ transactions (credit - debit). لا يوجد حقل balance مباشر لضمان الدقة والتدقيق. نحتفظ بـ balance_after لكل transaction كـ snapshot للأداء.

// في InvestorWallet Model public function getBalanceAttribute() { return $this->transactions() ->selectRaw(' SUM(CASE WHEN transaction_type="credit" THEN amount ELSE -amount END) as balance ')->value('balance') ?? 0; }
⚠️

تنبيه مهم بخصوص العمولة: العمولة تُؤخذ من عمولة المنصة (tasks_ads.commission) وليس من قيمة المهمة (tasks.total_price). يجب التأكد من وجود task_ad مرتبطة بالمهمة قبل حساب العمولة. إذا لم تكن المهمة معلنة (no ad)، يُمكن الاتفاق على قيمة عمولة ثابتة أو تأجيل الحساب.

✅ قائمة مهام التنفيذ

  • إضافة Scope: availableForInvestorPayment في Task Model
  • بناء InvestorTaskPaymentController@index مع منطق الفلترة الكامل
  • بناء InvestorTaskPaymentController@pay داخل DB Transaction
  • إضافة lockForUpdate لمنع Race Conditions
  • بناء دالة مشتركة processInvestorPayment تستخدمها كلا المسارين
  • إضافة خيار "دفع من مستثمر عام" في صفحة دفع المهمة بـ Admin
  • بناء getBalanceAttribute في InvestorWallet Model
  • تسجيل UserWalletTransaction عند كل عمولة تُحتسب
  • التعامل مع حالة عدم وجود task_ad عند حساب العمولة
  • إضافة التحقق من تاريخ انتهاء العقد قبل السماح بالدفع
  • كتابة Unit Tests لمنطق حساب العمولة
  • إضافة Notification للمستثمر عند نجاح الدفع وتسجيل العمولة
