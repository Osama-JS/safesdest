⚙التنفيذ التقني

1. إضافة دالة إرسال الموقع في LocationService:

safedest_driver/lib/services/location_service.dart
// Manual location send for testing Future>> sendLocationManually() async { try { debugPrint('Manual location send requested...'); // Check and request location permission final hasPermission = await _requestLocationPermission(); if (!hasPermission) { return ApiResponse>( success: false, message: 'لا توجد صلاحية للوصول للموقع الجغرافي', ); } // Get current location final position = await _getCurrentLocation(); if (position == null) { return ApiResponse>( success: false, message: 'فشل في الحصول على الموقع الحالي', ); } // Send location to server await _sendLocationUpdate(position); return ApiResponse>( success: true, message: 'تم إرسال الموقع بنجاح', data: { 'latitude': position.latitude, 'longitude': position.longitude, 'accuracy': position.accuracy, 'timestamp': DateTime.now().toIso8601String(), }, ); } catch (e) { return ApiResponse>( success: false, message: 'خطأ في إرسال الموقع: $e', ); } }

🧪اختبار الوظيفة

للاختبار: تأكد من تفعيل GPS في الهاتف قبل الاختبار

📋 خطوات الاختبار:

1️⃣ اختبار أساسي

  • تأكد من ظهور الزر عند Online
  • تأكد من اختفاء الزر عند Offline
  • اضغط على الزر واختبر الاستجابة

2️⃣ اختبار الصلاحيات

  • اختبر مع GPS مغلق
  • اختبر مع عدم وجود صلاحيات
  • تأكد من ظهور رسائل الخطأ

3️⃣ اختبار الإرسال

  • تأكد من إرسال الموقع للخادم
  • فحص Laravel logs
  • تأكد من دقة البيانات المرسلة

4️⃣ اختبار واجهة المستخدم

  • تأكد من ظهور Loading dialog
  • تأكد من ظهور SnackBar
  • اختبر عرض تفاصيل الموقع

🔍 ما يجب ملاحظته:

  • دقة الموقع: يجب أن تكون أقل من 50 متر في الظروف العادية
  • سرعة الاستجابة: يجب الحصول على الموقع خلال 10 ثوان
  • رسائل الخطأ: يجب أن تكون واضحة ومفيدة
  • Laravel Logs: يجب ظهور log "start update location"
