🏗️ البنية المعمارية

  • MapService: خدمة إدارة بيانات الخريطة مع Singleton pattern
  • MapModels: نماذج البيانات (TaskMapData, DriverLocation, MapMarker)
  • MapHomeScreen: الشاشة الرئيسية بالخريطة التفاعلية
  • TaskDetailsBottomSheet: عرض تفاصيل المهام
  • Custom Markers: أيقونات مخصصة مرسومة برمجياً
