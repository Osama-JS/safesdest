🚀 خطة التنفيذ الشاملة

⏱️ الوقت المقدر: 4-6 ساعات عمل لإكمال جميع الخطوات

إنشاء مشروع Firebase

إنشاء مشروع جديد في Firebase Console وإضافة تطبيق Android

  1. الذهاب إلى https://console.firebase.google.com/
  2. إنشاء مشروع جديد: "SafeDests Driver"
  3. إضافة تطبيق Android بـ package name: com.example.safedestsss
  4. تحميل google-services.json

إعداد تطبيق Flutter

تفعيل Firebase packages وإضافة ملفات التكوين

  1. نسخ google-services.json إلى android/app/
  2. إلغاء تعليق Firebase packages في pubspec.yaml
  3. تحديث android/build.gradle
  4. تحديث android/app/build.gradle
  5. flutter pub get

إعداد منصة Laravel

تثبيت Firebase Admin SDK وإعداد متغيرات البيئة

  1. composer require kreait/firebase-php
  2. إضافة Firebase service account key
  3. تحديث ملف .env بإعدادات Firebase
  4. إنشاء Firebase service class

⚙️ التفاصيل التقنية للتنفيذ

🔧 إعدادات Firebase في Flutter

📝 تحديث pubspec.yaml

# إلغاء تعليق هذه الحزم dependencies: firebase_core: ^2.24.2 firebase_messaging: ^14.7.9 flutter_local_notifications: ^17.2.2

🔨 إعدادات Android Gradle

// في android/build.gradle buildscript { dependencies { classpath 'com.google.gms:google-services:4.3.15' } } // في android/app/build.gradle apply plugin: 'com.google.gms.google-services' dependencies { implementation platform('com.google.firebase:firebase-bom:32.7.0') implementation 'com.google.firebase:firebase-messaging' }

🖥️ إعدادات Laravel Firebase

📦 تثبيت Firebase Admin SDK

composer require kreait/firebase-php # إضافة إلى config/services.php 'firebase' => [ 'project_id' => env('FIREBASE_PROJECT_ID'), 'credentials' => env('FIREBASE_CREDENTIALS'), ],

🔑 متغيرات البيئة المطلوبة

# إضافة إلى .env FIREBASE_PROJECT_ID=safedests-driver FIREBASE_CREDENTIALS=path/to/service-account-key.json FCM_SERVER_KEY=your-server-key-here
