نظام مبيعات وفواتير المنتجات

رؤية شاملة لتحويل طلبات المنتجات إلى دورة مبيعات متكاملة وموثقة

1. الرؤية والملخص التنفيذي

بناءً على التوجيهات الجديدة، ننتقل من مجرد "طلب توصيل" إلى "نظام مبيعات متكامل". الهدف هو توثيق كل عملية شراء بفاتورة رسمية (Sales Invoice) تحتوي على تفاصيل دقيقة للمنتج والسعر، تتبع حالة الدفع، ومن ثم ربط هذه الفاتورة بمهمة التوصيل (Delivery Task). هذا يضمن دقة مالية، مرجعية قانونية، وتسلسلاً منطقياً للعمليات.

2. دورة العمل المقترحة (The Workflow)

تم تصميم دورة العمل لتكون احترافية وتغطي كافة الجوانب المالية واللوجستية:

1
إنشاء أمر الشراء (Purchase Order)

يقوم المدير باختيار العميل (المستفيد) والمنتج والكمية.

  • يقوم النظام بعرض اسم المنتج، سعر الوحدة، والكمية بوضوح.
  • حساب السعر الإجمالي (سعر الوحدة × الكمية) تلقائياً.
  • إضافة أي رسوم إضافية (ضرائب، رسوم خدمة).
  • المخرج: إنشاء سجل "فاتورة مبيعات" (Sales Invoice) وسجلات "تفاصيل الفاتورة" (Invoice Items).
2
تفاصيل الفاتورة والدفع (Invoice Details & Payment)

يتم عرض الفاتورة بشكل تفصيلي قبل الدفع، وتحتوي على:

نموذج محتويات الفاتورة:
المنتج (Product) الكمية (Qty) سعر الوحدة (Unit Price) الإجمالي (Total)
اسم المنتج المختار 10 50 ر.س 500 ر.س
المجموع الكلي (Grand Total) 500 ر.س
  • تحديد طريقة الدفع (نقد، تحويل بنكي، محفظة إلكترونية).
  • عند تأكيد الدفع، تتحول حالة الفاتورة إلى "مدفوع" (Paid).
3
التنفيذ اللوجستي (Fulfillment)

بعد تأكيد الدفع، يتم إنشاء مهمة التوصيل.

  • ربط المهمة برقم الفاتورة (Sales Invoice ID) لضمان التتبع.
  • تعبئة بيانات "نقطة الاستلام" من موقع المنتج، و"نقطة التسليم" من عنوان العميل.

3. الهيكل البرمجي وقاعدة البيانات

لتحقيق هذا النظام باحترافية، سنعتمد هيكلية (Master-Detail) للفواتير، حيث يتم فصل بيانات الفاتورة الأساسية عن تفاصيل المنتجات.

أ. جدول فواتير المبيعات (sales_invoice) - Master

يحتوي على البيانات العامة للفاتورة.

Schema::table('sales_invoice', function (Blueprint $table) {
  $table->string('invoice_number')->unique(); // رقم الفاتورة المرجعي
  $table->enum('status', ['pending', 'paid', 'cancelled', 'refunded'])->default('pending');
  $table->string('payment_method')->nullable(); // cash, bank_transfer, wallet
  $table->timestamp('paid_at')->nullable(); // تاريخ الدفع
  $table->decimal('total_amount', 10, 2); // مجموع أسعار المنتجات
  $table->decimal('tax_amount', 10, 2)->default(0);
  $table->decimal('delivery_fee', 10, 2)->default(0);
  $table->decimal('final_total', 10, 2); // المبلغ النهائي المطلوب
  $table->text('notes')->nullable();
  $table->unsignedBigInteger('created_by'); // Admin User ID
});

ب. جدول تفاصيل الفاتورة (sales_invoice_details) - Detail

يحتوي على المنتجات المشمولة في الفاتورة (يتم تخزين بيانات هذا الجدول عند إنشاء الفاتورة).

Schema::create('sales_invoice_details', function (Blueprint $table) {
  $table->id();
  $table->unsignedBigInteger('sales_invoice_id');
  $table->unsignedBigInteger('product_id');
  $table->string('product_name'); // Snapshot of product name
  $table->integer('quantity');
  $table->decimal('unit_price', 10, 2);
  $table->decimal('line_total', 10, 2); // quantity * unit_price
  $table->timestamps();

  $table->foreign('sales_invoice_id')->references('id')->on('sales_invoice')->onDelete('cascade');
  $table->foreign('product_id')->references('id')->on('products');
});

ج. تحديث جدول المهام (tasks)

Schema::table('tasks', function (Blueprint $table) {
  $table->unsignedBigInteger('sales_invoice_id')->nullable();
  $table->foreign('sales_invoice_id')->references('id')->on('sales_invoice');
});

4. استراتيجية التنفيذ والتطوير

وحدة إدارة المبيعات (Sales Module)

  • SalesController: وحدة تحكم جديدة لإدارة الفواتير (Master) وتفاصيلها (Details).
  • Invoice View: تصميم صفحة فاتورة احترافية تقوم بجلب البيانات من جدول sales_invoice_details لعرض قائمة المنتجات.

الربط مع المهام (Task Integration)

  • إضافة زر "Create Delivery Task" في صفحة عرض الفاتورة.
  • هذا الزر ينقل المستخدم لإنشاء المهمة مع تمرير بيانات الفاتورة.

5. توصيات للجودة والاحترافية

💡
التدقيق المالي: يجب أن لا يسمح النظام بتعديل الفاتورة بعد دفعها إلا بصلاحيات خاصة.
  • تنبيهات تلقائية: إرسال إشعار للعميل عند إصدار الفاتورة، وعند تأكيد الدفع.
  • لوحة تحكم (Dashboard): إضافة قسم يعرض "إجمالي المبيعات" و"الفواتير غير المدفوعة".
