🧪 تعليمات اختبار Email Job

اختبار شامل لنظام إرسال الإيميلات باستخدام Laravel Queue

الخطوة 1: فحص الإعدادات الأساسية

تأكد من أن جميع الإعدادات صحيحة:

php artisan tinker >>> config('queue.default') >>> config('mail.default') >>> DB::table('jobs')->count() >>> exit

الخطوة 2: إرسال Email Job للاختبار

قم بتشغيل الأوامر التالية في tinker:

php artisan tinker // فحص عدد Jobs قبل الإرسال >>> $jobsBefore = DB::table('jobs')->count(); >>> echo "Jobs before: $jobsBefore\n"; // إعداد بيانات الإيميل >>> $emailData = [ 'to' => 'osamomy@gmail.com', 'subject' => 'Test Email from SafeDests - ' . now()->format('Y-m-d H:i:s'), 'template' => 'emails.notification', 'type' => 'test_email', 'priority' => 'high', 'user_name' => 'Test User', 'content' => 'This is a test email to verify the email system is working.', 'action_url' => 'https://example.com/test', 'action_text' => 'Test Action', 'additional_data' => [ 'Test Time' => now()->format('Y-m-d H:i:s'), 'Test ID' => uniqid('test_'), 'System Status' => 'Testing' ] ]; // إرسال Job >>> dispatch(new App\Jobs\SendEmailNotificationJob($emailData)); >>> echo "Job dispatched!\n"; // فحص عدد Jobs بعد الإرسال >>> $jobsAfter = DB::table('jobs')->count(); >>> echo "Jobs after: $jobsAfter\n"; >>> exit

الخطوة 3: فحص تفاصيل Job

تحقق من أن Job تم إنشاؤه بشكل صحيح:

php artisan tinker // عرض آخر Job >>> $latestJob = DB::table('jobs')->orderBy('id', 'desc')->first(); >>> if ($latestJob) { echo "Job ID: " . $latestJob->id . "\n"; echo "Queue: " . $latestJob->queue . "\n"; echo "Available at: " . date('Y-m-d H:i:s', $latestJob->available_at) . "\n"; echo "Current time: " . date('Y-m-d H:i:s') . "\n"; echo "Ready: " . ($latestJob->available_at <= time() ? 'YES' : 'NO') . "\n"; } // فحص محتوى Job >>> $payload = json_decode($latestJob->payload, true); >>> if (isset($payload['data']['command'])) { echo "Job contains valid command\n"; $command = unserialize($payload['data']['command']); echo "Email to: " . $command->emailData['to'] . "\n"; } >>> exit

الخطوة 4: تشغيل Queue Worker

جرب تشغيل Queue Worker بطرق مختلفة:

الطريقة 1: تشغيل Job واحد

php artisan queue:work --once --verbose

الطريقة 2: تشغيل مع timeout أطول

php artisan queue:work --verbose --timeout=120 --memory=512

الطريقة 3: تحديد queue محدد

php artisan queue:work database --verbose

الخطوة 5: المعالجة اليدوية (إذا لم تعمل الطرق السابقة)

إذا لم يعمل Queue Worker، جرب المعالجة اليدوية:

php artisan tinker // الحصول على أول Job >>> $job = DB::table('jobs')->first(); >>> if ($job) { echo "Processing job manually...\n"; $payload = json_decode($job->payload, true); $command = unserialize($payload['data']['command']); // تشغيل Job $command->handle(); echo "Job executed!\n"; // حذف Job DB::table('jobs')->where('id', $job->id)->delete(); echo "Job removed from queue\n"; } >>> exit

الخطوة 6: فحص النتائج

📧 فحص الإيميل

  • تحقق من صندوق الوارد: osamomy@gmail.com
  • تحقق من مجلد الرسائل غير المرغوب فيها
  • ابحث عن رسالة بعنوان: "Test Email from SafeDests"

📊 فحص قاعدة البيانات

php artisan tinker >>> DB::table('jobs')->count() // يجب أن يكون 0 إذا تم التشغيل >>> DB::table('failed_jobs')->count() // فحص Jobs الفاشلة >>> DB::table('email_notifications_log')->count() // فحص سجل الإيميلات >>> exit

📝 فحص السجلات

# في terminal منفصل tail -f storage/logs/laravel.log # أو فحص آخر 50 سطر tail -50 storage/logs/laravel.log

الخطوة 7: استكشاف الأخطاء

⚠️ إذا لم يتم إرسال الإيميل

تحقق من:

  • إعدادات SMTP في ملف .env
  • أن خدمة البريد الإلكتروني تعمل
  • أن الإيميل ليس في مجلد الرسائل غير المرغوب فيها
  • سجلات Laravel للأخطاء

⚠️ إذا لم يتم معالجة Jobs

جرب:

  • مسح cache: php artisan config:clear
  • إعادة تشغيل queue: php artisan queue:restart
  • فحص أذونات قاعدة البيانات
  • زيادة memory limit و timeout

✅ علامات النجاح

  • Job تم إضافته لجدول jobs
  • Queue worker عالج Job بنجاح
  • Job تم حذفه من جدول jobs
  • تم تسجيل العملية في email_notifications_log
  • وصل الإيميل لصندوق الوارد

الخطوة 8: اختبار تعيين مهمة حقيقية

بعد التأكد من عمل النظام، جرب تعيين مهمة حقيقية:

  1. اذهب لصفحة المهام في لوحة الإدارة
  2. اختر مهمة في حالة "in_progress" أو "advertised"
  3. قم بتعيين سائق لها
  4. راقب إرسال الإشعارات
  5. تحقق من وصول الإيميلات للسائق وصاحب المهمة
