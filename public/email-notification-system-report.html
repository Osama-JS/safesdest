🚀 نظام الإشعارات عبر الإيميل

نظام متكامل لإرسال الإشعارات باستخدام Jobs & Queues مع إمكانية إرفاق الملفات

📋 نظرة عامة

تم إنشاء نظام شامل لإرسال الإشعارات عبر الإيميل يتميز بالمرونة والأداء العالي. النظام يستخدم Laravel Jobs و Queues لضمان عدم تأثير إرسال الإيميلات على أداء التطبيق الرئيسي.

💡 طرق الاستخدام

1. الاستخدام الأساسي

إرسال إشعار بسيط

use App\Services\EmailNotificationService; $emailService = new EmailNotificationService(); $emailService->send([ 'to' => 'user@example.com', 'subject' => 'إشعار جديد', 'content' => 'محتوى الإشعار هنا', 'user_name' => 'أحمد محمد' ]);

2. استخدام Helper Class

إرسال إشعار تعيين مهمة

use App\Helpers\NotificationHelper; // إرسال إشعار تعيين مهمة للسائق NotificationHelper::sendTaskAssigned($driver, $task); // إرسال إشعار استلام دفعة NotificationHelper::sendPaymentReceived($user, 500, 'TXN123', 'دفعة مهمة');

3. إرسال مع مرفقات

إرسال إيميل مع ملف PDF

$attachments = [ [ 'path' => 'invoices/invoice_123.pdf', 'name' => 'فاتورة_123.pdf', 'mime' => 'application/pdf' ] ]; $emailService->send([ 'to' => 'customer@example.com', 'subject' => 'فاتورتك جاهزة', 'content' => 'تجد مرفق فاتورتك', 'template' => 'emails.notification' ], $attachments);

4. الإرسال المجمع

إرسال لعدة مستلمين

$recipients = ['user1@example.com', 'user2@example.com', 'user3@example.com']; $emailService->sendBulk($recipients, [ 'subject' => 'إشعار صيانة النظام', 'content' => 'سيتم إجراء صيانة للنظام غداً', 'template' => 'emails.notification', 'priority' => 'high' ]);

5. الإرسال المؤجل

إرسال بعد فترة زمنية محددة

// إرسال بعد 30 دقيقة $emailService->send([ 'to' => 'user@example.com', 'subject' => 'تذكير بالمهمة', 'content' => 'لا تنس إكمال مهمتك' ], [], '30 minutes'); // إرسال بأولوية منخفضة مع تأخير $emailService->sendLowPriority([ 'to' => 'user@example.com', 'subject' => 'تقرير أسبوعي', 'content' => 'تقرير أنشطة الأسبوع' ], [], '1 hour');

⚙️ الإعدادات المطلوبة

1. إعدادات البريد الإلكتروني (.env)

MAIL_MAILER=smtp MAIL_HOST=smtp.gmail.com MAIL_PORT=587 MAIL_USERNAME=your-email@gmail.com MAIL_PASSWORD=your-app-password MAIL_ENCRYPTION=tls MAIL_FROM_ADDRESS=your-email@gmail.com MAIL_FROM_NAME="${APP_NAME}"

2. إعدادات Queue (.env)

QUEUE_CONNECTION=database DB_QUEUE_TABLE=jobs DB_QUEUE=default DB_QUEUE_RETRY_AFTER=90

3. تشغيل Queue Worker

# تشغيل worker للمعالجة المستمرة php artisan queue:work # تشغيل worker مع إعدادات محددة php artisan queue:work --queue=high,default,low --timeout=60 # تشغيل worker في الخلفية (Linux/Mac) nohup php artisan queue:work > /dev/null 2>&1 &

⚠️ تنبيه مهم

يجب تشغيل Queue Worker باستمرار لمعالجة الإشعارات. في بيئة الإنتاج، استخدم Supervisor أو مدير عمليات مشابه.

🔧 الميزات المتقدمة

1. نظام الأولويات

ℹ️ مستويات الأولوية

  • high: للإشعارات العاجلة (تنبيهات أمنية، أخطاء نظام)
  • normal: للإشعارات العادية (تعيين مهام، تحديثات)
  • low: للإشعارات غير العاجلة (تقارير، نشرات)

2. نظام إعادة المحاولة

// في SendEmailNotificationJob public $tries = 3; // عدد المحاولات public $timeout = 120; // مهلة زمنية بالثواني public $backoff = [30, 60, 120]; // فترات الانتظار بين المحاولات

3. معالجة الإشعارات المتأخرة

# تشغيل معالج الإشعارات المتأخرة php artisan notifications:process-pending # مع خيارات مخصصة php artisan notifications:process-pending --limit=100 --max-attempts=5

4. مراقبة النظام

استعلامات مفيدة لمراقبة النظام

use App\Models\EmailNotificationLog; // إحصائيات اليوم $todayStats = [ 'sent' => EmailNotificationLog::sent()->today()->count(), 'failed' => EmailNotificationLog::failed()->today()->count(), 'pending' => EmailNotificationLog::pending()->today()->count() ]; // الإشعارات عالية الأولوية المعلقة $highPriorityPending = EmailNotificationLog::highPriority() ->pending() ->where('created_at', '<', now()->subMinutes(5)) ->get(); // معدل نجاح الإرسال هذا الشهر $thisMonth = EmailNotificationLog::thisMonth(); $successRate = ($thisMonth->sent()->count() / $thisMonth->count()) * 100;

✅ أفضل الممارسات

🚀 الأداء

  • استخدم الأولويات بحكمة
  • تجنب الإرسال المتزامن للكميات الكبيرة
  • راقب حالة Queue Workers
  • استخدم Redis للـ Queues في الإنتاج
  • قم بتنظيف السجلات القديمة دورياً

🔒 الأمان

  • تحقق من صحة عناوين البريد
  • استخدم HTTPS للروابط
  • لا تضع معلومات حساسة في المحتوى
  • استخدم التوقيع الرقمي للروابط
  • راقب محاولات الإرسال المشبوهة

⚠️ تحذيرات مهمة

  • لا تستخدم النظام لإرسال رسائل تسويقية غير مرغوب فيها
  • تأكد من وجود آلية إلغاء الاشتراك
  • احترم حدود مزود البريد الإلكتروني
  • قم بعمل نسخ احتياطية من سجلات الإشعارات

🔧 استكشاف الأخطاء وإصلاحها

المشاكل الشائعة والحلول

1. الإشعارات لا تُرسل

# تحقق من حالة Queue php artisan queue:failed # إعادة تشغيل Queue Worker php artisan queue:restart # تحقق من إعدادات البريد php artisan tinker Mail::raw('Test', function($msg) { $msg->to('test@example.com')->subject('Test'); });

2. الإشعارات بطيئة

# زيادة عدد Workers php artisan queue:work --sleep=3 --tries=3 --max-time=3600 # استخدام Redis بدلاً من Database QUEUE_CONNECTION=redis

3. مراقبة الأخطاء

# عرض الأخطاء الأخيرة php artisan queue:failed # إعادة معالجة الإشعارات الفاشلة php artisan queue:retry all # مسح الإشعارات الفاشلة php artisan queue:flush
