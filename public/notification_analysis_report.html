2. الخدمات (Services)

📦 NotificationService.php

المسار: app/Services/NotificationService.php

الوظائف الرئيسية:

  • send() - إرسال إشعار لمجموعة من المستخدمين
  • sendNewTaskNotificationToDriver() - إشعار السائق بمهمة جديدة
  • sendTaskUpdateNotificationToDriver() - إشعار السائق بتحديث المهمة
  • sendPaymentNotificationToDriver() - إشعار السائق بعملية دفع
// مثال على استخدام NotificationService $notificationService = new NotificationService(); // إرسال إشعار لسائقين محددين $notificationService->send( type: 'driver', ids: [1, 2, 3], title: 'إشعار جديد', body: 'لديك مهمة جديدة', notif_type: 'new_task' );

⚡ الإشعارات التلقائية الحالية

1. إشعار مهمة جديدة (New Task)

المحفز: عند إنشاء مهمة جديدة وتعيينها لسائق

المستلم: السائق المعين

البيانات: عنوان الاستلام، عنوان التسليم، السعر

$notificationService->sendNewTaskNotificationToDriver($driver, $task);

2. إشعار تحديث المهمة (Task Update)

المحفز: عند تغيير حالة المهمة

المستلم: السائق المعين

الحالات: accepted, in_progress, completed, cancelled

$notificationService->sendTaskUpdateNotificationToDriver($driver, $task, $status);

3. إشعار الدفع (Payment)

المحفز: عند إضافة مبلغ للمحفظة

المستلم: السائق

البيانات: المبلغ، نوع العملية

$notificationService->sendPaymentNotificationToDriver($driver, $amount, 'payment_received');

🚀 خطة التنفيذ التفصيلية

المرحلة 1: إنشاء Controller جديد

📁 الملف: ManualNotificationController.php

المسار: app/Http/Controllers/admin/ManualNotificationController.php

<?php namespace App\Http\Controllers\admin; use App\Http\Controllers\Controller; use App\Services\NotificationService; use App\Models\Driver; use App\Models\Customer; use App\Models\Task; use Illuminate\Http\Request; class ManualNotificationController extends Controller { protected $notificationService; public function __construct(NotificationService $notificationService) { $this->notificationService = $notificationService; } /** * إرسال إشعار لسائق واحد */ public function sendToDriver(Request $request) { $request->validate([ 'driver_id' => 'required|exists:drivers,id', 'title' => 'required|string|max:255', 'body' => 'required|string|max:500', 'type' => 'nullable|string' ]); $result = $this->notificationService->send( type: 'driver', ids: [$request->driver_id], title: $request->title, body: $request->body, notif_type: $request->type ?? 'admin_message' ); return response()->json([ 'success' => true, 'message' => 'تم إرسال الإشعار بنجاح' ]); } /** * إرسال إشعار لعدة سائقين */ public function sendToMultipleDrivers(Request $request) { $request->validate([ 'driver_ids' => 'required|array', 'driver_ids.*' => 'exists:drivers,id', 'title' => 'required|string|max:255', 'body' => 'required|string|max:500', 'type' => 'nullable|string' ]); $result = $this->notificationService->send( type: 'driver', ids: $request->driver_ids, title: $request->title, body: $request->body, notif_type: $request->type ?? 'admin_message' ); return response()->json([ 'success' => true, 'message' => 'تم إرسال الإشعارات بنجاح', 'count' => count($request->driver_ids) ]); } /** * إرسال إشعار للسائق من صفحة المهمة */ public function sendToTaskDriver(Request $request) { $request->validate([ 'task_id' => 'required|exists:tasks,id', 'title' => 'required|string|max:255', 'body' => 'required|string|max:500' ]); $task = Task::with('driver')->findOrFail($request->task_id); if (!$task->driver_id) { return response()->json([ 'success' => false, 'message' => 'لا يوجد سائق معين لهذه المهمة' ], 400); } $result = $this->notificationService->send( type: 'driver', ids: [$task->driver_id], title: $request->title, body: $request->body, notif_type: 'task_message' ); return response()->json([ 'success' => true, 'message' => 'تم إرسال الإشعار للسائق بنجاح', 'driver' => $task->driver->name ]); } }

🔒 الاعتبارات الأمنية

⚠️ نقاط مهمة يجب مراعاتها

  • التحقق من الصلاحيات: التأكد من أن المستخدم لديه صلاحية إرسال الإشعارات
  • تحديد معدل الإرسال: منع إرسال عدد كبير من الإشعارات في وقت قصير (Rate Limiting)
  • التحقق من المدخلات: تنظيف وتحقق من جميع المدخلات لمنع XSS
  • سجل الأنشطة: تسجيل جميع الإشعارات المرسلة للمراجعة
  • التحقق من FCM Token: التأكد من صلاحية الـ token قبل الإرسال
