🔧 دليل حل مشاكل Laravel Queue

حل مشكلة عدم تشغيل Jobs المخزنة في قاعدة البيانات

🔍 تحليل المشكلة

❌ المشكلة الحالية

العمليات (Jobs) يتم تخزينها في جدول jobs ولكن الأمر php artisan queue:work لا يقوم بتشغيلها.

الأسباب المحتملة:

  • مشكلة في إعدادات Queue
  • عدم تشغيل Queue Worker بشكل صحيح
  • مشكلة في أذونات قاعدة البيانات
  • خطأ في تكوين الـ Jobs
  • مشكلة في الـ timeout أو memory limit

🛠️ الحل خطوة بخطوة

الخطوة 1: فحص إعدادات Queue

تأكد من أن إعدادات Queue صحيحة في ملف .env:

# في ملف .env QUEUE_CONNECTION=database DB_QUEUE_TABLE=jobs DB_QUEUE=default

الخطوة 2: فحص جدول Jobs

تأكد من وجود الجدول وأن البيانات موجودة:

# فحص الجدول php artisan tinker >>> DB::table('jobs')->count() >>> DB::table('jobs')->get()

الخطوة 3: مسح Cache التكوين

امسح جميع أنواع Cache:

php artisan config:clear php artisan cache:clear php artisan route:clear php artisan view:clear

الخطوة 4: إعادة تشغيل Queue Worker

أوقف جميع العمليات وأعد التشغيل:

# إيقاف جميع Workers php artisan queue:restart # تشغيل Worker جديد مع تفاصيل php artisan queue:work --verbose --tries=3 --timeout=60

الخطوة 5: فحص الأخطاء

راقب الأخطاء في الوقت الفعلي:

# مراقبة ملف السجل tail -f storage/logs/laravel.log # فحص Failed Jobs php artisan queue:failed

🔬 استكشاف الأخطاء المتقدم

1. فحص تفصيلي للـ Jobs:

# فحص Jobs في قاعدة البيانات php artisan tinker >>> $jobs = DB::table('jobs')->get(); >>> foreach($jobs as $job) { ... echo "ID: {$job->id}, Queue: {$job->queue}, Attempts: {$job->attempts}\n"; ... echo "Available at: " . date('Y-m-d H:i:s', $job->available_at) . "\n"; ... echo "Created at: " . date('Y-m-d H:i:s', $job->created_at) . "\n\n"; ... }

2. اختبار Job بسيط:

# إنشاء Job اختبار php artisan make:job TestJob # في TestJob.php public function handle() { \Log::info('Test Job executed successfully!'); } # تشغيل Job اختبار php artisan tinker >>> dispatch(new App\Jobs\TestJob());

3. فحص أذونات قاعدة البيانات:

# اختبار الاتصال بقاعدة البيانات php artisan tinker >>> DB::connection()->getPdo() >>> DB::table('jobs')->insert([ ... 'queue' => 'default', ... 'payload' => json_encode(['test' => 'data']), ... 'attempts' => 0, ... 'reserved_at' => null, ... 'available_at' => time(), ... 'created_at' => time() ... ]);

💡 الحلول الشائعة

⚠️ مشكلة الوقت (Timezone)

تأكد من أن التوقيت صحيح في التطبيق:

# في config/app.php 'timezone' => 'Asia/Riyadh', # أو في .env APP_TIMEZONE=Asia/Riyadh

⚠️ مشكلة Memory Limit

زيادة حد الذاكرة:

# تشغيل مع ذاكرة أكبر php -d memory_limit=512M artisan queue:work # أو في php.ini memory_limit = 512M

⚠️ مشكلة Database Connection

تأكد من استقرار الاتصال:

# في config/database.php 'mysql' => [ // ... 'options' => [ PDO::ATTR_EMULATE_PREPARES => true, PDO::MYSQL_ATTR_USE_BUFFERED_QUERY => true, ], ],

🔄 المعالجة اليدوية

معالجة Jobs يدوياً

إذا لم تعمل الطرق السابقة، يمكنك معالجة Jobs يدوياً:

php artisan tinker # الحصول على أول Job >>> $job = DB::table('jobs')->first(); # فك تشفير البيانات >>> $payload = json_decode($job->payload, true); >>> $command = unserialize($payload['data']['command']); # تشغيل Job يدوياً >>> $command->handle(); # حذف Job بعد التشغيل >>> DB::table('jobs')->where('id', $job->id)->delete();

إعادة جدولة Jobs

إعادة إنشاء Jobs جديدة:

# الحصول على جميع Jobs المعلقة >>> $jobs = DB::table('jobs')->get(); # إعادة إنشاء كل Job >>> foreach($jobs as $job) { ... $payload = json_decode($job->payload, true); ... $command = unserialize($payload['data']['command']); ... dispatch($command); ... } # حذف Jobs القديمة >>> DB::table('jobs')->truncate();

🛡️ منع تكرار المشكلة

قائمة فحص دورية:

  • مراقبة عدد Jobs في قاعدة البيانات
  • فحص ملفات السجل بانتظام
  • تشغيل Queue Worker كخدمة نظام
  • إعداد مراقبة تلقائية للـ Queue
  • اختبار Jobs دورياً
  • نسخ احتياطية منتظمة لقاعدة البيانات

✅ إعداد Supervisor (موصى به)

لضمان تشغيل Queue Worker باستمرار:

# تثبيت Supervisor sudo apt-get install supervisor # إنشاء ملف تكوين sudo nano /etc/supervisor/conf.d/laravel-worker.conf [program:laravel-worker] process_name=%(program_name)s_%(process_num)02d command=php /path/to/your/project/artisan queue:work --sleep=3 --tries=3 autostart=true autorestart=true user=www-data numprocs=1 redirect_stderr=true stdout_logfile=/path/to/your/project/storage/logs/worker.log # إعادة تحميل Supervisor sudo supervisorctl reread sudo supervisorctl update sudo supervisorctl start laravel-worker:*

⚡ أوامر سريعة للاستكشاف

# فحص سريع للنظام php artisan queue:work --once --verbose php artisan queue:failed php artisan config:cache php artisan queue:restart # مراقبة مباشرة watch -n 2 'php artisan tinker --execute="echo DB::table(\"jobs\")->count() . \" jobs pending\n\";"' # تنظيف شامل php artisan queue:flush php artisan queue:restart php artisan config:clear php artisan cache:clear # اختبار سريع php artisan tinker --execute="dispatch(new App\Jobs\SendEmailNotificationJob(['to' => 'test@test.com', 'subject' => 'Test']));"
