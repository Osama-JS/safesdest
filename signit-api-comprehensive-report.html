🔐 3. نظام المصادقة والأمان

🛡️ OAuth 2.0 Client Credentials Flow

يستخدم SignIt API نظام OAuth 2.0 مع Client Credentials Grant للمصادقة، مما يوفر مستوى عالي من الأمان.

📋 متطلبات المصادقة:

المعامل الوصف مطلوب
client_id معرف العميل المقدم من SignIt ✅
client_secret المفتاح السري للعميل ✅
grant_type نوع المنحة (client_credentials) ✅
scope نطاق الصلاحيات المطلوبة ✅

🔑 الصلاحيات المتاحة:

  • signature-requests:read - قراءة طلبات التوقيع
  • signature-requests:write - إنشاء وتعديل طلبات التوقيع
  • documents:read - قراءة الوثائق
  • documents:write - رفع وإدارة الوثائق
// إعداد المصادقة في Laravel 'signit' => [ 'base_url' => env('SIGNIT_BASE_URL', 'https://api.signit.sa/v1'), 'client_id' => env('SIGNIT_CLIENT_ID'), 'client_secret' => env('SIGNIT_CLIENT_SECRET'), 'scope' => env('SIGNIT_SCOPE', 'signature-requests:read signature-requests:write'), ],
📈 4. حالة التنفيذ الحالية

✅ الوظائف المُنفذة:

الوظيفة الحالة الملف الملاحظات
المصادقة OAuth مُكتمل SignitService::getAccessToken() يدعم Basic Authentication
إنشاء طلب التوقيع جزئي SignitService::createSignatureRequest() يحتاج تحسين وإضافة معاملات
التحقق من الحالة مُكتمل SignitService::getSignatureStatus() يعمل بشكل صحيح
إدارة الأخطاء أساسي جميع الطرق يحتاج تحسين وتفصيل

❌ الوظائف المفقودة:

  • إدارة الوثائق المتعددة
  • التوقيع المتسلسل والمتعدد
  • إرسال التذكيرات
  • إلغاء طلبات التوقيع
  • تحميل الوثائق الموقعة
  • نظام Webhooks للإشعارات
  • إدارة القوالب
  • تتبع تفصيلي للأحداث

🗄️ هيكل قاعدة البيانات المقترح

-- جدول طلبات التوقيع CREATE TABLE signature_requests ( id BIGINT PRIMARY KEY AUTO_INCREMENT, signit_id VARCHAR(255) UNIQUE NOT NULL, title VARCHAR(255) NOT NULL, message TEXT, status ENUM('pending', 'completed', 'cancelled', 'expired') DEFAULT 'pending', created_by BIGINT, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, completed_at TIMESTAMP NULL, expires_at TIMESTAMP NULL, INDEX idx_status (status), INDEX idx_created_by (created_by) ); -- جدول الوثائق CREATE TABLE documents ( id BIGINT PRIMARY KEY AUTO_INCREMENT, signature_request_id BIGINT, name VARCHAR(255) NOT NULL, original_name VARCHAR(255), file_path VARCHAR(500), file_size BIGINT, mime_type VARCHAR(100), is_signed BOOLEAN DEFAULT FALSE, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (signature_request_id) REFERENCES signature_requests(id) ON DELETE CASCADE ); -- جدول الموقعين CREATE TABLE signers ( id BIGINT PRIMARY KEY AUTO_INCREMENT, signature_request_id BIGINT, email VARCHAR(255) NOT NULL, name VARCHAR(255) NOT NULL, order_index INT DEFAULT 1, status ENUM('pending', 'signed', 'declined') DEFAULT 'pending', signed_at TIMESTAMP NULL, ip_address VARCHAR(45), user_agent TEXT, FOREIGN KEY (signature_request_id) REFERENCES signature_requests(id) ON DELETE CASCADE );
