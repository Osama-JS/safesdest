📊 هيكل قاعدة البيانات

🗃️ جدول tasks_ads

id (Primary Key) task_id (Foreign Key → tasks) description (وصف الإعلان) status (running/closed) highest_price (أعلى سعر) lowest_price (أقل سعر) included (شامل الضريبة) closed_at (تاريخ الإغلاق) service_commission (عمولة الخدمة) service_commission_type (نوع العمولة) vat_commission (عمولة الضريبة)

🗃️ جدول tasks_offers

id (Primary Key) task_ad_id (Foreign Key → tasks_ads) driver_id (Foreign Key → drivers) price (سعر العرض) description (وصف العرض) accepted (مقبول/مرفوض)

📋 حالات النظام

الحالة الوصف الإجراءات المتاحة
advertised المهمة في حالة إعلان عرض للسائقين، استقبال عروض
running الإعلان نشط ويستقبل عروض تقديم عروض، تعديل عروض
closed الإعلان مغلق عرض العروض المقدمة فقط

🔌 APIs المطلوبة للتطبيق المحمول

📱 APIs السائق

API Endpoint Method الوصف المعاملات
/api/driver/task-ads GET جلب إعلانات المهام المتاحة page, per_page, status
/api/driver/task-ads/{id} GET تفاصيل إعلان محدد id
/api/driver/task-ads/{id}/offers POST تقديم عرض على إعلان price, description
/api/driver/task-ads/offers/{id} PUT تعديل عرض مقدم price, description
/api/driver/task-ads/offers/{id}/accept POST قبول المهمة بعد الموافقة offer_id
/api/driver/my-offers GET عروض السائق المقدمة page, per_page

📱 الشاشات المطلوبة في التطبيق

شاشة إعلانات المهام الرئيسية

المسار: lib/screens/task_ads/task_ads_screen.dart

الوظائف:

  • عرض قائمة الإعلانات المتاحة
  • فلترة حسب الحالة (متاحة، مقدم عليها عرض، مقبولة)
  • البحث في الإعلانات
  • تحديث القائمة (Pull to Refresh)
  • التنقل لتفاصيل الإعلان

شاشة تفاصيل الإعلان

المسار: lib/screens/task_ads/task_ad_detail_screen.dart

الوظائف:

  • عرض تفاصيل الإعلان كاملة
  • عرض معلومات المهمة (نقاط الاستلام والتسليم)
  • عرض النطاق السعري
  • عرض العرض المقدم (إن وجد)
  • إمكانية تقديم/تعديل العرض
  • عرض حالة الإعلان

شاشة تقديم العرض

المسار: lib/screens/task_ads/submit_offer_screen.dart

الوظائف:

  • نموذج إدخال السعر المقترح
  • حقل وصف العرض
  • التحقق من صحة البيانات
  • عرض النطاق السعري المطلوب
  • حفظ/تحديث العرض

شاشة عروضي

المسار: lib/screens/task_ads/my_offers_screen.dart

الوظائف:

  • عرض جميع العروض المقدمة
  • فلترة حسب الحالة (قيد المراجعة، مقبول، مرفوض)
  • إمكانية تعديل العروض غير المقبولة
  • عرض تفاصيل كل عرض
  • التنقل لتفاصيل الإعلان
