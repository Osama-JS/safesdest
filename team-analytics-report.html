تقرير مفصل - صفحة إحصائيات الفريق

دليل شامل لجميع الإحصائيات والمؤشرات المعروضة في لوحة تحكم الفريق

نظرة عامة على النظام

صفحة إحصائيات الفريق هي لوحة تحكم شاملة تعرض جميع المؤشرات الأساسية لأداء الفريق، وتتضمن إحصائيات المهام، الإيرادات، أداء السائقين، واستخدام المركبات. جميع البيانات يتم استخراجها من قاعدة البيانات PostgreSQL باستخدام استعلامات محسنة.

مؤشرات الأداء الرئيسية (KPIs)
إجمالي المهام الشهرية

الوصف:

يعرض العدد الإجمالي للمهام التي تم إنشاؤها خلال الشهر الحالي لهذا الفريق.

مصدر البيانات: جدول tasks
طريقة الحساب:
SELECT COUNT(*) FROM tasks
WHERE team_id = {team_id}
AND EXTRACT(MONTH FROM created_at) = CURRENT_MONTH
AND EXTRACT(YEAR FROM created_at) = CURRENT_YEAR

الاستخدام:

  • مراقبة حجم العمل الشهري
  • مقارنة الأداء بين الأشهر
  • تخطيط الموارد المطلوبة
  • تقييم نمو الأعمال
ملاحظة: يتم تحديث هذا المؤشر في الوقت الفعلي مع كل مهمة جديدة.
معدل إنجاز المهام

الوصف:

نسبة المهام المكتملة من إجمالي المهام خلال الشهر الحالي، معبر عنها كنسبة مئوية.

مصدر البيانات: جدول tasks مع حالة status = 'completed'
طريقة الحساب:
معدل الإنجاز = (المهام المكتملة ÷ إجمالي المهام) × 100

completed_tasks = COUNT(*) WHERE status = 'completed'
total_tasks = COUNT(*)
completion_rate = (completed_tasks / total_tasks) * 100

المؤشرات المرتبطة:

  • 90%+ أداء ممتاز
  • 70-89% أداء جيد
  • 50-69% يحتاج تحسين
  • <50% أداء ضعيف

العوامل المؤثرة:

  • كفاءة السائقين
  • صعوبة المهام
  • توفر المركبات
  • الظروف الخارجية
إجمالي الإيرادات الشهرية

الوصف:

مجموع الإيرادات المحققة من المهام المكتملة خلال الشهر الحالي، محسوبة بالريال السعودي.

مصدر البيانات: حقل total_price من جدول tasks
طريقة الحساب:
SELECT SUM(total_price) FROM tasks
WHERE status = 'completed'
AND team_id = {team_id}
AND EXTRACT(MONTH FROM created_at) = CURRENT_MONTH

التحليل المالي:

  • تتبع الأداء المالي الشهري
  • مقارنة الإيرادات بين الفترات
  • حساب متوسط قيمة المهمة
  • تقييم ربحية الفريق
تنبيه: يتم احتساب الإيرادات فقط للمهام ذات الحالة "مكتملة".
معدل استخدام السائقين

الوصف:

نسبة السائقين النشطين من إجمالي السائقين في الفريق، مما يوضح مدى استغلال الموارد البشرية.

مصدر البيانات: جدول drivers مع حقل status
طريقة الحساب:
active_drivers = COUNT(*) WHERE status = 'active'
total_drivers = COUNT(*)
utilization = (active_drivers / total_drivers) * 100

مستويات الاستخدام:

  • 85%+ استخدام مثالي
  • 70-84% استخدام جيد
  • 50-69% استخدام متوسط
  • <50% استخدام منخفض

التحسينات المقترحة:

  • إعادة توزيع المهام
  • تدريب السائقين غير النشطين
  • مراجعة جداول العمل
الرسوم البيانية والتصورات

رسم بياني للمهام الشهرية

الغرض: عرض اتجاه المهام على مدار الأشهر لتحديد الأنماط الموسمية وتوقع الأحمال المستقبلية.

مصدر البيانات: 
SELECT EXTRACT(MONTH FROM created_at) as month, COUNT(*) as count
FROM tasks
WHERE team_id = {team_id}
AND EXTRACT(YEAR FROM created_at) = CURRENT_YEAR
GROUP BY month
ORDER BY month
المعلومات المعروضة:
  • عدد المهام لكل شهر
  • الاتجاه العام للنمو
  • الذروات والانخفاضات
  • المقارنة بين الأشهر

رسم دائري لتوزيع حالات المهام

الغرض: إظهار التوزيع النسبي لحالات المهام المختلفة لفهم تدفق العمل وتحديد الاختناقات.

مصدر البيانات: 
SELECT status, COUNT(*) as count
FROM tasks
WHERE team_id = {team_id}
GROUP BY status
الحالات المتتبعة:
  • مكتملة completed
  • قيد التنفيذ in_progress
  • معينة assigned
  • ملغية canceled

رسم بياني للإيرادات الشهرية

الغرض: تتبع الأداء المالي للفريق عبر الزمن وتحديد الاتجاهات المالية.

مصدر البيانات: 
SELECT EXTRACT(MONTH FROM created_at) as month,
       SUM(COALESCE(total_price, 0)) as revenue
FROM tasks
WHERE team_id = {team_id}
AND status = 'completed'
AND EXTRACT(YEAR FROM created_at) = CURRENT_YEAR
GROUP BY month
ORDER BY month
المؤشرات المالية:
  • الإيرادات الشهرية
  • معدل النمو
  • متوسط الإيرادات
  • التوقعات المستقبلية

رسم دائري لاستخدام المركبات

الغرض: عرض توزيع أحجام المركبات في الفريق لتحسين إدارة الأسطول.

مصدر البيانات: 
SELECT vehicle_size_id, COUNT(*) as count
FROM drivers
WHERE team_id = {team_id}
GROUP BY vehicle_size_id
أحجام المركبات:
  • صغيرة Small Vehicles
  • متوسطة Medium Vehicles
  • كبيرة Large Vehicles
الجداول التفصيلية والتحليلات
جدول أداء السائقين

الوصف: جدول مفصل يعرض إحصائيات كل سائق في الفريق مع مؤشرات الأداء الفردية.

البيان مصدر البيانات طريقة الحساب الاستخدام
اسم السائق drivers.name استعلام مباشر التعرف على السائق
المهام المكتملة tasks.status = 'completed' COUNT(*) WHERE driver_id = {id} قياس الإنتاجية
إجمالي المهام tasks.driver_id COUNT(*) WHERE driver_id = {id} حجم العمل المخصص
معدل النجاح حساب مشتق (المكتملة ÷ الإجمالي) × 100 تقييم الكفاءة
حجم المركبة drivers.vehicle_size_id JOIN مع جدول vehicle_sizes تصنيف القدرات
تحليل التغطية الجغرافية

الوصف:

تحليل مناطق العمل المخصصة للفريق وتقييم التغطية الجغرافية من خلال الـ Geofences.

مصدر البيانات:
  • جدول geofence_teams
  • جدول geofences
  • إحداثيات المهام من task_points

المؤشرات المحسوبة:

  • عدد المناطق المخصصة
  • معدل التغطية الجغرافية
  • المهام داخل/خارج المناطق
  • كفاءة التوزيع الجغرافي
حساب التغطية:
ST_Contains(geofence.coordinates,
ST_GeomFromText('POINT(longitude latitude)'))

الخلاصة النهائية

صفحة إحصائيات الفريق تمثل حلاً شاملاً ومتقدماً لمراقبة وتحليل أداء الفرق في نظام SafeDests. تجمع الصفحة بين الدقة في البيانات والسهولة في الاستخدام، مما يوفر للمديرين والمشرفين أدوات قوية لاتخاذ قرارات مدروسة وتحسين الأداء العام للفريق.
